# 朝礼・広告費レポートの設定ファイル

自動レポートが実行時に読む設定です（GitHub Actionsのランナーでも必要なため、
`data/` ではなくこのフォルダにコミットして置きます）。

| ファイル | 中身 | 更新する人 |
|---|---|---|
| `events-YYYY-MM.json` | 月間目標（1.1億/1.2億）とイベント日程・重み | 月初に更新 |
| `amazon-manual-YYYY-MM.json` | Amazon日別売上の手動控え（SP-API停止中の補完。キントーン添付があればそちらが優先） | 添付漏れの日だけ |
| `adcost-extra-YYYY-MM.json` | 自動で取れない広告費（ガジェティ/TDA/TikTok/案件費/TV）の手動値 | 値が変わったとき |

## ★重要★ このリポジトリは公開です

ここに置いてよいのは **日別・媒体別の集計値まで**（朝礼台本でChatworkに
流しているのと同じ粒度）。注文明細・顧客情報・認証情報は絶対に置かないこと。
実データのCSVは従来どおり `data/`（gitignore済み）へ。
