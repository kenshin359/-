# Shopifyのトークンを発行する（最初の1回だけ）

これができると、**Shopifyの売上が毎朝8:00に自動でキントーンに入ります。**
CSVのダウンロードは不要になります。

所要 約10分。**発行したトークンに期限はありません。**

---

## なぜこの手順が必要なのか

以前は Shopify管理画面の「アプリを開発」→「アプリを作成」で
`shpat_` から始まるトークンがその場で表示されました。

**Shopifyはこの方式を廃止しました。**
いまは Dev Dashboard でアプリを作る形になり、
画面に出るのは「クライアントID」と「シークレット」だけです。

そこで、Shopifyが定めた**正規の手順（OAuth）**でトークンを1回だけ発行します。

---

## 準備：Dev Dashboardで「戻り先URL」を登録する（1回だけ）

Shopifyは、**あらかじめ登録しておいたURLにしか**戻してくれません。

1. Dev Dashboard → アプリ **キントーン** → **バージョン** → 新しいバージョンを作成
2. 一番下の **リダイレクトURL** に、次を1行だけ入れる

```
https://localhost/shopify/callback
```

3. **リリース**

> このURLは開けなくてかまいません。**アドレス欄に付いてくる文字を使うだけ**です。

---

## 手順①：GitHubにSecretsを4つ登録する

リポジトリ →「Settings」→「Secrets and variables」→「Actions」

| 名前 | 値 | どこにあるか |
|---|---|---|
| `SHOPIFY_SHOP_DOMAIN` | `qawrc2-vf.myshopify.com` | すでに判明済み |
| `SHOPIFY_CLIENT_ID` | `03a7f...` | Dev Dashboard → 設定 → 資格情報 |
| `SHOPIFY_CLIENT_SECRET` | （目のマークで表示してコピー） | 同上 |
| `CHATWORK_SECRET_ROOM_ID` | 社長の**マイチャット**のルームID | Chatworkでマイチャットを開いたURLの末尾の数字 |

> ⚠️ **シークレットはチャットに貼らないでください。** Secretsの画面に直接入力してください。
> ⚠️ `CHATWORK_SECRET_ROOM_ID` は**必ずマイチャット（自分だけが見える場所）**にしてください。
> グループにするとトークンが他の社員にも見えてしまいます。

---

## 手順②：承認用のURLを出す

「Actions」タブ →「**Shopifyトークンを発行（初回のみ）**」→「**Run workflow**」

**`code` の欄は空のまま**実行してください。

ログに、次のようなURLが出ます。

```
https://qawrc2-vf.myshopify.com/admin/oauth/authorize?client_id=…&scope=read_orders,read_products&…
```

---

## 手順③：ブラウザで承認する

1. そのURLをコピーしてブラウザで開く
2. 「このアプリは**注文の閲覧**と**商品の閲覧**を求めています」という画面が出る
   - **求められている権限が読み取り2つだけ**であることを確認
3. **インストール／承認**を押す
4. **「このサイトにアクセスできません」**という画面になります → **それで正常です**
5. ブラウザの**アドレス欄をまるごとコピー**

```
https://localhost/shopify/callback?code=xxxxxxxx&hmac=…&shop=qawrc2-vf.myshopify.com&…
```

> ⏱ **この `code` は数分で切れます。** 次の手順④をすぐに行ってください。
> 切れても、②からやり直せば何度でもできます。

---

## 手順④：トークンに交換する

もう一度「**Shopifyトークンを発行（初回のみ）**」→「**Run workflow**」

今度は **`code` の欄に、さっきコピーしたアドレス欄をまるごと貼り付け**て実行します。

（`code=` の部分だけ抜き出さなくて大丈夫です。まるごとで読み取ります）

---

## 手順⑤：届いたトークンをSecretsに入れる

**Chatworkのマイチャット**にトークンが届きます。

1. その1行をコピー
2. GitHubのSecretsに **`SHOPIFY_ADMIN_TOKEN`** という名前で登録
3. **Chatworkのメッセージを削除する**

> トークンは**実行ログには出しません。**
> このリポジトリは公開されているため、ログに出すと誰でも読めてしまいます。

---

## 手順⑥：動かしてみる

「Actions」→「**Shopify売上取込（毎朝8:00）**」→「Run workflow」

- そのまま実行 → **昨日ぶん**
- `from` `to` に日付を入れる → その期間（例: `2026-07-01` 〜 `2026-07-31`）

うまくいけば、**あとは毎朝8:00に自動**です。

---

## うまくいかないときは

| 症状 | 原因と対処 |
|---|---|
| `code の期限切れ` | 数分で切れます。手順②からやり直してください |
| `code をすでに1回使っている` | 使い捨てです。手順②からやり直してください |
| 承認画面で `redirect_uri is not whitelisted` | 「準備」のリダイレクトURL登録が未反映です。**リリース**まで行ったか確認してください |
| Chatworkに届かない | `CHATWORK_SECRET_ROOM_ID` か `CHATWORK_API_TOKEN` の設定漏れです |

---

## これができなくても、売上は取り込めます

トークンが取れなくても、**CSV方式がすでに動きます**（`docs/shopify-自動連携.md`）。

Shopifyで注文CSVをエクスポートして、キントーンの提出ボックスの
「売上｜Shopify(自社)」に置くだけです。集計結果はまったく同じになります。

**急ぐ必要はありません。** うまくいかなければCSVで運用を始めて、
あとからトークンに切り替えても問題ありません。
