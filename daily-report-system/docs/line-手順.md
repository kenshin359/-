# LINE通知の設定手順（画面どおりに進めるだけ）

所要 **約20分**。ブラウザだけで完結します。

---

## 全体の流れ

```
① LINE公式アカウントを作る          5分
② Messaging APIを有効にする         5分
③ トークンを発行する                2分
④ 送信先IDを調べる                  5分  ← ここが唯一の難所
⑤ n8nに設定してテスト               3分
```

---

## ① LINE公式アカウントを作る

1. **https://manager.line.biz** を開く
2. 自分のLINEアカウントでログイン
3. 「**作成**」をクリック
4. 入力する項目：
   - アカウント名：`Libetee 日報` （何でもOK。**社長・部長に表示される名前**です）
   - 業種：小売業 など
5. 作成完了

---

## ② Messaging APIを有効にする

1. 作ったアカウントの管理画面で、右上の「**設定**」
2. 左メニューの「**Messaging API**」
3. 「**Messaging APIを利用する**」をクリック
4. 「開発者情報」を求められたら、名前とメールを入力
5. プロバイダーを選ぶ（初回は新規作成。名前は `Libetee` などでOK）

### あわせて設定しておくこと

同じ「Messaging API」の画面で：

| 項目 | 設定 |
|---|---|
| 応答メッセージ | **オフ** |
| あいさつメッセージ | オフ（お好みで） |
| Webhook | **オン**（④で使います） |

---

## ③ トークンを発行する

1. **https://developers.line.biz/console/** を開く
2. さきほどのプロバイダー → 作成されたチャネルをクリック
3. 「**Messaging API設定**」タブを開く
4. 一番下の「**チャネルアクセストークン（長期）**」の「**発行**」をクリック
5. 表示された長い文字列を**コピーしてメモ帳に貼る**

> ⚠️ これが `LINE_CHANNEL_ACCESS_TOKEN` になります。
> **他人に渡さないでください。** これがあれば誰でもあなたの公式アカウントから送信できます。

---

## ④ 送信先IDを調べる

**「誰に送るか」を指定するID**が必要です。目的に応じて2通りあります。

### パターンA：社長ひとりに送る（最速・3分）

1. LINE Developers Console で「**チャネル基本設定**」タブを開く
2. 下のほうにある「**あなたのユーザーID**」をコピー
   - これは**チャネルを作った人（＝いま操作しているあなた）のID**です
3. **そのアカウントで、作った公式アカウントを友だち追加**する
   - 「Messaging API設定」タブのQRコードをスマホで読み取る
4. 完了。これが `LINE_TARGET_USER_ID` です

> ⚠️ **友だち追加を忘れると送信できません。** ここでつまずく人が一番多いです。

### パターンB：グループに送る（社長・部長がいる場所／5分）

グループIDは画面に表示されないため、**一度だけLINEから受け取って調べます**。

**手順：**

1. n8n に `workflow-4-line-id-finder.json` を読み込む
   ```
   https://raw.githubusercontent.com/kenshin359/-/claude/kintone-daily-report-system-f8migr/daily-report-system/n8n/workflow-4-line-id-finder.json
   ```
2. ワークフローを開き、右上のスイッチを「**Active**」にする
3. 「LINEからの通知を受ける」ノードをクリックし、
   **Production URL** をコピー（`https://....../webhook/libetee-line-id`）
4. LINE Developers Console →「Messaging API設定」→
   **Webhook URL** に貼り付けて「更新」→「**Webhookの利用**」をオン
5. LINEアプリで、**社長・部長・Botの3人のグループを作る**
   - Botを招待するには「Messaging API設定」で
     **「グループトーク・複数人トークへの参加を許可する」をオン**にしておくこと
6. **そのグループで何でもいいのでメッセージを送る**（「テスト」など）
7. n8n の左メニュー「**Executions**」を開く → いま届いた実行をクリック
8. 「★送信先IDを表示」ノードに、こう出ます：

```
種類            : group
★ここをコピー   : Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
設定する変数    : LINE_TARGET_GROUP_ID
```

9. この `Cxxxx...` をコピー
10. **終わったら、このワークフローは「Inactive」に戻してください**（役目は終わりです）

---

## ⑤ n8nに設定してテスト

n8n の「Settings → Variables」に追加します。

| 変数名 | 値 |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | ③でコピーしたトークン |
| `LINE_TARGET_GROUP_ID` | ④Bのグループ ID（Aの場合は空でOK） |
| `LINE_TARGET_USER_ID` | ④AのユーザーID（Bの場合は空でOK） |
| `NOTIFY_CHANNELS` | `auto` |

**両方入れた場合はグループが優先**されます。

### テスト

`workflow-3-notify-on-submit`（日報の即時通知）を開いて「**Test workflow**」。
誰かが日報を出していれば、LINEに届きます。

届かないときは下の表を確認してください。

---

## うまくいかないときは

| 症状 | 原因 | 直し方 |
|---|---|---|
| `401` エラー | トークンが違う | ③をやり直して再発行 |
| `400` エラー `Invalid to` | 送信先IDが違う | ④をやり直す。`U` や `C` で始まる長い文字列か確認 |
| エラーは出ないが届かない | **Botを友だち追加していない** | QRコードから友だち追加（パターンA） |
| グループに届かない | Botがグループにいない | Botをグループに招待。「グループトーク参加を許可」がオンか確認 |
| `429` エラー | 無料通数を超えた | 下の「費用」を参照 |

---

## 💰 費用について（重要）

**LINE公式アカウントの無料プランは、月200通までです。**

御社の想定：

```
日報の即時通知   1日3〜5件 × 22営業日 = 約 66〜110通
毎日のまとめ     1日1通 × 22営業日    = 約 22通
──────────────────────────────
合計                                  約 88〜132通／月
```

**無料枠にはギリギリ収まりますが、余裕はありません。**
人が増えたり通知を細かくすると、すぐ超えます。超えると有料プラン（月5,000円〜）が必要です。

> **チャットワークには通数制限がありません。**
> 「毎回の日報通知はチャットワーク、緊急のときだけLINE」という分け方にすれば、
> 無料枠に十分収まります。設定は `NOTIFY_CHANNELS` で切り替えられます。

---

## まとめ：あなたが控える値

作業が終わったら、この2つ（または3つ）が手元にあるはずです。

```
LINE_CHANNEL_ACCESS_TOKEN = （③で発行した長い文字列）
LINE_TARGET_GROUP_ID      = C から始まる文字列   ← グループに送る場合
LINE_TARGET_USER_ID       = U から始まる文字列   ← 個人に送る場合
```

これを n8n の変数に入れれば完了です。
**トークンはチャットに貼らないでください。** n8nの画面に直接入力してください。
