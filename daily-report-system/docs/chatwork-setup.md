# Chatwork 設定書

LINE の代わりに、または LINE と併用して、Chatwork へ通知を送れます。

---

## 1. APIトークンを取得する（3分）

1. Chatwork にログイン
2. 画面**右上の自分の名前**をクリック
3. 「**サービス連携**」を選ぶ
4. 左メニューの「**API Token**」
5. パスワードを入力すると、トークンが表示されます → **コピー**

> 発行されるのは**あなた個人のトークン**です。通知はあなたの名前で投稿されます。
> 会社として運用するなら、**連携用アカウントを作ってそのトークンを使う**のが望ましいです。

## 2. ルームIDを調べる（1分）

1. 通知したいルーム（グループチャット）を Chatwork で開く
2. ブラウザのアドレス欄を見る

```
https://www.chatwork.com/#!rid123456789
                              ↑ この数字がルームID
```

`123456789` の部分だけを控えてください。

## 3. 設定する

`.env`（または n8n の変数）に入れます。

```
CHATWORK_API_TOKEN=（1で取得したトークン）
CHATWORK_ROOM_ID=123456789
```

## 4. テスト送信

```bash
npm run notify-test
```

`APP_ENV=test` の間は実送信されず、本文プレビューだけ出ます。
本番で試すときは `.env` の `APP_ENV=production` に変更してください。

---

## 送信先の切り替え

`.env` の `NOTIFY_CHANNELS` で決まります。

| 設定値 | 動き |
|---|---|
| `auto`（既定） | 設定が入っているものすべてに送る。**おすすめ** |
| `line` | LINEだけ |
| `chatwork` | Chatworkだけ |
| `both` | 両方 |

`auto` なら、Chatworkのトークンだけ入れれば Chatwork にだけ届きます。
LINEの設定を消す必要はありません。

> **片方が失敗しても、もう片方には届きます。** 通知が全く来ない事態を避けるためです。

---

## 表示のされ方

Chatwork では枠付きで表示されます。

```
[info][title]📝 日報が届きました（2026-07-29）[/title]
久保さん（LP）

【要点】自社サイトの改修を4件完了。配送遅延のお知らせを追加。
...
[/info]
```

**緊急と判定された場合は `[toall]` が付き、ルーム全員に通知が飛びます。**
うるさい場合は `.env` に `CHATWORK_MENTION_ALL_ON_URGENT=false` を設定してください。

---

## 制限

- 1メッセージが長い場合は **4,000文字ごとに自動分割**して連投します
- Chatwork API のレート制限に当たった場合は、自動で待って再試行します（最大4回）

## LINE と Chatwork、どちらがよいか

| | LINE | Chatwork |
|---|---|---|
| 気づきやすさ | ◎ スマホに直接届く | ○ 業務時間内なら十分 |
| 履歴の追いやすさ | △ 流れてしまう | ◎ タスク化・検索ができる |
| 全員への呼びかけ | △ | ◎ `[toall]` が使える |
| 設定の手間 | 多い（公式アカウント作成が必要） | **少ない（トークンとルームIDだけ）** |

**急ぎの判断を求めるなら LINE、記録として残すなら Chatwork。**
両方使う（`auto` のまま両方設定）のが、実は一番おすすめです。
