# Kintone「日次CSV提出ボックス」

毎朝スタッフが、その日ぶんのCSVを**1画面にまとめて置く**ための部屋です。

| 種類 | 置き場 |
|---|---|
| 売上 | Amazon / 楽天 / Shopify(自社) / TikTok Shop |
| 広告 | Meta広告 / RPP(楽天) / Google広告 / その他広告 |

**1レコード＝1日**。8つの置き場が縦に並ぶだけの、迷いようのない画面です。

---

## 1. 作り方

```bash
npm run create-business-apps intake
```

作られると `KINTONE_INTAKE_APP_ID=27` のような行が出ます。**`.env` に貼ってください。**

---

## 2. 毎朝の流れ

```
① スタッフが kintone を開き、今日のレコードに8つのCSVを置く
        ↓
② npm run intake:check   … 何が足りないかをChatworkに知らせる
        ↓
③ npm run intake:import  … 広告CSVを「広告費管理」アプリへ自動で取り込む
                             売上CSVは集計して報告する
```

②③は自動実行に載せられます（`docs/自動送信の設定.md` と同じ仕組み）。

### ファイル名は自由です

置き場で媒体が決まるので、**ファイル名は何でも構いません。**
「ダウンロード (3).csv」のままでも正しく読みます。

---

## 3. 項目

| 項目名 | 種類 | 必須 | 備考 |
|---|---|---|---|
| 対象日 | 日付 | ○ | 既定は今日 |
| 提出者 | ユーザー選択 | | 既定はログイン中の本人 |
| 売上｜Amazon 〜 売上｜TikTok Shop | 添付ファイル | | 4つ |
| 広告｜Meta広告 〜 広告｜その他広告 | 添付ファイル | | 4つ |
| 状態 | ドロップダウン | | 提出中 / 提出完了 / 取込済み / 対象外(休業日) |
| 取込ログ（自動記入） | 文字列(複数行) | | スクリプトが書き戻します。手で書く欄ではありません |
| 備考 | 文字列(複数行) | | |
| 重複防止キー | 文字列(1行) | | 日付そのもの。**「値の重複を禁止する」にチェック** |

### 一覧

| 一覧名 | 中身 |
|---|---|
| 今日 | 今日ぶん |
| 今週 | 今週ぶん |
| 未取込 | まだ取り込んでいない日（休業日は除く） |
| すべて | 全期間 |

## 4. なぜ「8個そろった」を画面に出さないのか

**kintoneの計算式は、ファイルが入っているかどうかを見られません。**

そのため「8個中いくつ揃ったか」をアプリの中で自動表示することができません。
手動チェックの欄を作ることもできますが、**チェックを付け忘れた瞬間に嘘の表示**になります。

そこで、判定は `npm run intake:check` が行い、**Chatworkに知らせる**形にしました。

```
📥 CSV提出チェック（2026-07-31 金）

そろっている: 2 / 8

【売上】
　✅ 売上｜Amazon（1件）
　⬜ 売上｜楽天
　⬜ 売上｜Shopify(自社)
　⬜ 売上｜TikTok Shop

【広告】
　✅ 広告｜Meta広告（1件）
　⬜ 広告｜RPP(楽天)
　⬜ 広告｜Google広告
　⬜ 広告｜その他広告

【未提出】
　・売上｜楽天
　…
```

**そろっている日も送ります。**
連絡が来ないとき、「全部そろった」のか「チェックが止まっている」のか
区別がつかなくなるためです。

休業日などで元々ファイルが出ない日は、**状態を「対象外(休業日)」**にすれば催促しません。

---

## 5. コマンド

```bash
npm run intake:check                    # 今日の提出状況を表示
npm run intake:check -- --send          # Chatwork にも送る
npm run intake:check -- --create        # 今日の受け皿レコードが無ければ作る
npm run intake:check -- --date=2026-07-31

npm run intake:import                   # 取り込む
npm run intake:import -- --dry-run      # 書き込まず内容だけ表示
npm run intake:import -- --send         # 結果を Chatwork にも送る
```

`intake:check` は、足りないものがあると**終了コード1**を返します。
自動実行のときに「今日は未提出があった」と気づけるようにするためです。

## 6. 取り込みのルール

### 広告CSV → 「広告費管理」アプリへ書き込みます

- 同じ日・同じ媒体を2回取り込んでも**二重になりません**（その媒体だけ入れ替え）
- **期間まとめのCSVは取り込みません。**
  「7/1〜7/30が1行」のファイルは、どの日にいくら使ったか分からないためです。
  日数で等分すると「昨日の広告費」が嘘になります。
  → 各媒体のレポートで「**日別（Daily）**」を選んで書き出し直してください。

### 売上CSV → 集計して報告するだけです

**kintoneには書き込みません。**
売上・転換率報告アプリは**人が手で入力している**ため、
自動で書き足すと、どちらが正しいのか分からなくなります。

---

## 7. 文字コードについて

楽天やAmazonのCSVは **Shift_JIS** のことがあります。

ファイルを**文字列として受け取ると、その時点で日本語が壊れて元に戻せません。**
そのため、添付ファイルは必ず**バイト列のまま**取り出し、
文字コードの判定は `lib/csv.js` に任せています（UTF-8 / UTF-16 / Shift_JIS を自動判定）。

---

## 8. 列名が合わないとき

「読めませんでした（日付の列が見つかりません）」と出たら、
**`config/sales-mapping.json`** に実物の列名を追記してください。
プログラムを触る必要はありません。

現時点で **TikTok Shop / Google広告 / その他広告** の列名は**推測で入れています**。
実物のCSVをいただければ、正式な列名に差し替えます（各設定に `_要確認` と書いてあります）。
