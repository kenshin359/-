# 한국 SNS(명동) 보고 양식 / 韓国チーム向け報告フォーマット

촬영 → 편집 → 게시 → 광고 → 유입 → 예약까지 하나로 이어서 관리하기 위한 보고 양식입니다.
아래 양식을 **그대로 복사해서** 채팅에 보내고, 같은 내용을 kintone 앱
**「韓国SNS運用管理（明洞）」**(한국 SNS 운영 관리) 에 입력해 주세요.

보고는 **월말 정리 + 그때그때 보고** 두 가지를 모두 진행합니다.

## kintone 입력 순서

1. 촬영이 정해지면 레코드를 **새로 만들고** 계정(Tiffany / ONA)과 ①의 항목을 입력 → 진행 상태를 `① 事前共有済み` 로
2. 촬영이 끝나면 ②를 입력 → `② 撮影済み`, 편집을 시작하면 `③ 編集中`
3. 게시하면 게시 상세에 한 줄 추가 → `④ 投稿済み`(광고 운용 중이면 `⑤ 広告運用中`)
4. 유입·예약·매출을 입력 → `⑥ 成果集計済み`

## 자동으로 확인되는 항목 (주간 리포트)

아래는 매주 자동으로 점검되어 일본 측과 공유됩니다. 빈칸이 그대로 미보고로 표시됩니다.

| 표시 | 내용 |
|---|---|
| 🔴 | 사전 공유 없음 / 2일 전 규칙 위반 |
| 🔴 | 촬영 후 보고 없음 (촬영 다음 날 이후) |
| 🔴 | 편집 완료 예정일 초과 (담당자 이름과 함께 표시) |
| 🔴 | 게시 예정일이 지났는데 게시 기록 없음 |
| 🔴 | 게시 후 7일이 지나도 유입·예약 미입력 |
| 🟡 | 게시 URL 미입력 / 매체·형태·종류 미입력 / 광고를 썼는데 광고비 미입력 |

궁금한 점이나 양식에서 채우기 어려운 항목이 있으면, 비워 두지 말고 **무엇이 막혔는지** 적어 주세요.
