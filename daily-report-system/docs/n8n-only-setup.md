# ブラウザだけで完結する導入手順（ターミナル不要）

**黒い画面（ターミナル）は一切使いません。** すべてブラウザの操作だけです。
やることは「コピー＆貼り付け」と「ボタンを押す」だけ。所要 約60分。

---

## 全体の流れ

```
【1回だけの準備】
  ① Claude APIキーを取る          … 5分
  ② LINEの設定をする              … 15分
  ③ n8n に登録する                … 5分
  ④ n8n に設定値を貼り付ける      … 10分
  ⑤ ファイルを3つ読み込む         … 5分
  ⑥ 初期設定を1回だけ実行         … 1分
  ⑦ テスト実行して中身を確認      … 5分
  ⑧ 自動運転をONにする            … 1分

【あとは毎日自動】
  毎日19:00に、日報が自動でまとまってLINEに届きます。
  あなたは何もしなくて大丈夫です。
```

---

## ① Claude APIキーを取る（5分）

1. **https://console.anthropic.com** を開く
2. Googleアカウントでログイン
3. 左メニュー「**API Keys**」→「**Create Key**」
4. 名前は `libetee` などでOK →「Create」
5. `sk-ant-` で始まる文字列を**コピーしてメモ帳に貼っておく**

> ⚠️ この画面を閉じると**二度と表示されません**。必ずメモしてください。
> 💡 支払い方法の登録が必要です。**Usage limits で月1,000円などの上限**を設定しておくと安心です。

---

## ② LINEの設定をする（15分）

### 2-1. 公式アカウントを作る
1. **https://manager.line.biz** →「作成」
2. 名前は `Libetee 日報` などでOK

### 2-2. Messaging API を有効にする
1. 作ったアカウントの「**設定**」→「**Messaging API**」→「**Messaging APIを利用する**」
2. 「**チャネルアクセストークン（長期）**」を**発行してコピー・メモ**

### 2-3. 送信先を決める
1. 社長・部長・Bot の3人でLINEグループを作る
2. LINE Developers → 対象チャネル →「**グループトークへの参加を許可する**」をON

> グループIDの調べ方が難しい場合は、**まず社長個人あて**でも動きます。
> その場合、社長がBotを友だち追加してください。IDは後で設定できます。

---

## ③ n8n に登録する（5分）

1. **https://n8n.io** →「Get started free」
2. メールアドレスで登録（クレジットカード不要でお試しできます）
3. ログインすると、作業画面が開きます

> 💰 **料金について（正直に）**：n8n Cloud は無料お試し期間のあと**有料**（月20ユーロ前後）です。
> 費用をかけたくない場合は、この手順の代わりに **パソコンで動かす方法**（`docs/START-HERE.md`）もあります。
> ただしその場合はターミナル操作が必要になります。

---

## ④ n8n に設定値を貼り付ける（10分）

n8n の画面で **Settings（設定）→ Variables（変数）** を開き、
下の表のとおりに1つずつ追加してください。**名前は1文字も変えずにコピー**してください。

| 名前（そのままコピー） | 値 |
|---|---|
| `KINTONE_BASE_URL` | `https://w6pq7i12hn4b.cybozu.com` |
| `KINTONE_USER` | Kintoneのログイン**ID** |
| `KINTONE_PASSWORD` | Kintoneの**パスワード** |
| `KINTONE_DAILY_REPORT_APP_ID` | `6` |
| `KINTONE_AI_REPORT_APP_ID` | いったん `0`（⑥のあとで書き換えます） |
| `ANTHROPIC_API_KEY` | ①でメモしたキー |
| `ANTHROPIC_MODEL` | `claude-sonnet-5` |
| `LINE_CHANNEL_ACCESS_TOKEN` | ②でメモしたトークン |
| `LINE_TARGET_GROUP_ID` | グループID（無ければ空でOK） |
| `LINE_TARGET_USER_ID` | 個人ID（無ければ空でOK） |
| `REPORT_TIMEZONE` | `Asia/Tokyo` |
| `WEBHOOK_SECRET` | 好きな長い文字列（例 `libetee-2026-himitsu-9f3a`） |

> **Kintoneのパスワードを入れるのが不安な場合**：
> ⑥のあとに「APIトークン」方式へ切り替えられます（`docs/kintone-*.md` 参照）。
> まずは動かすことを優先して大丈夫です。

## ⑤ ファイルを3つ読み込む（5分）

このプロジェクトの `n8n/` フォルダにある3つのファイルを、n8nに読み込ませます。

1. n8n の画面右上「**…**」→「**Import from File**」
2. 下の3つを**1つずつ**読み込む

| ファイル | 役割 |
|---|---|
| `workflow-0-setup.json` | **初期設定**（1回だけ使う） |
| `workflow-1-daily-report.json` | **毎日の日報**（本番） |
| `workflow-2-urgent-webhook.json` | **緊急通知**（本番） |

---

## ⑥ 初期設定を1回だけ実行（1分）

1. **「Libetee ⓪初期設定」** を開く
2. 左上の「**▶ここを押して実行**」→ 画面下の「**Test workflow**」ボタンを押す
3. 数秒待つと、最後のノードに番号が出ます：

```
✅ AI経営日報アプリを作成しました
KINTONE_AI_REPORT_APP_ID: 26
```

4. **この番号（例：26）を、④の `KINTONE_AI_REPORT_APP_ID` に上書き**してください

> これで、AIが作った報告を保存する場所がKintoneにできました。
> このワークフローはもう使いません。

---

## ⑦ テスト実行して中身を確認（5分）

1. **「Libetee ①定時 経営日報」** を開く
2. 「**Test workflow**」ボタンを押す
3. 各ノードに緑のチェックが付けば成功です
4. **LINEに日報が届く**ので、中身を確認してください

### うまくいかないときの見方

失敗したノードは**赤く**なります。そのノードをクリックすると理由が出ます。

| 表示 | 意味 | 直し方 |
|---|---|---|
| `401` | ID・パスワード・キーが違う | ④の値を見直す |
| `404` | アプリIDが違う | `KINTONE_DAILY_REPORT_APP_ID` が `6` か確認 |
| `日報は1件以上?` で止まる | その日の日報が無い | 正常です。日報がある日に再実行 |

**赤いノードの画面をそのまま写真に撮って送っていただければ、こちらで判断します。**

---

## ⑧ 自動運転をONにする（1分）

1. 「Libetee ①定時 経営日報」の右上のスイッチを「**Active**」にする
2. 「Libetee ②緊急 即時通知」も「**Active**」にする

**これで完了です。** 毎日19:00に自動で日報が届きます。

### 送信時刻を変えたい場合

「定時トリガー」ノードをクリック → `0 19 * * *` の `19` を変えるだけです
（例：18時なら `0 18 * * *`）。

---

## これ以降、あなたがやること

**何もありません。**

- 毎日19:00にLINEへ届きます
- 内容はKintoneの「AI経営日報」アプリにも保存されます
- スタッフの日報の書き方は**今までどおりで大丈夫**です

### 唯一のお願い（スタッフの方へ）

急ぎの件は、日報の本文に「**至急**」または「**緊急**」と書いてください。
その言葉があると、AIが緊急と判断して赤信号🔴で知らせます。

---

## 困ったときは

- **LINEが来ない** → n8nの「Executions」で赤い実行を探し、その画面を撮って送ってください
- **内容がおかしい** → 何日の分がどうおかしかったか教えてください。AIへの指示文を調整します
- **止めたい** → n8nのスイッチを「Inactive」にすれば止まります
