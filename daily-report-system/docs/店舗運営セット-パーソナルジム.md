# 店舗運営セット（パーソナルジム・Excel3点）

O2ジムの店舗責任者が毎日使う3点を、Excelで作って配布できるようにしたものです。

| # | ファイル | 作るコマンド | 何に使うか |
|---|---|---|---|
| ① | `out/店舗責任者_業務マニュアル_<担当者>さん.xlsx` | `npm run manual:store` | 日次・週次・月次のチェック、トレーナー教育、KPI、上司報告 |
| ② | `out/会員手続き書類_<店舗>.xlsx` | `npm run forms:member` | 入会同意書・休会届・退会届・受付台帳（A4印刷してそのまま記入） |
| ③ | `out/シフト表_<店舗>_<YYYY-MM>.xlsx` | `npm run shift` | 月間シフト、労働時間・人件費・人数不足・開店／閉店の穴の自動チェック |

```bash
cd daily-report-system
pip install openpyxl        # 初回だけ
npm run store:all           # 3点まとめて作る
```

担当者・店舗・対象月を変えるとき：

```bash
python3 scripts/buildStoreManual.py --name=高山 --store=梅田店 --month=2026-10 --to=北野
python3 scripts/buildMemberForms.py --store=梅田店
python3 scripts/buildShiftSheet.py  --store=梅田店 --month=2026-10
```

**パソコンが苦手な人向け**：GitHub の「Actions」→「店舗運営セット（Excel3点）」→ `Run workflow`
で担当者名・店舗名・対象月を入れて実行すると、3点まとめてダウンロードできます。

文面や項目を直すときは **Excelではなく設定JSONを直して作り直す**のが原則です。

| 直すファイル | 反映されるExcel |
|---|---|
| `config/store-manual.json` | ① 業務マニュアル |
| `config/member-forms.json` | ② 会員手続き書類 |
| `config/shift.json` | ③ シフト表 |

## ① 業務マニュアル（9シート）

| シート | いつ使うか | 自動計算 |
|---|---|---|
| 使い方 | 最初に1回読む。3つの役割（店を回す／育てる／数字で報告する）と守ること | — |
| 日次チェック | 毎日。開店前5・営業中5・閉店後5の15項目に ✓ か ー | 実施率・当日の実施数 |
| 週次チェック | 週1回。数値ふり返り・1on1・翌週シフト・退会リスク会員の洗い出し・設備点検 | 実施率 |
| 月次チェック | 月1回。翌月シフト・目標合意・休会退会の締切処理・月報・育成計画 | 完了率 |
| 教育カリキュラム | トレーナーを採ったとき／レベルを上げるとき。到達基準は全部数字 | — |
| 習得状況 | 1on1のあと。トレーナー別に12項目を1〜4で記入 | 平均・Lv判定・項目平均 |
| KPI記録 | 毎日、閉店後。**報告の数字はすべてここから取る** | 入会率・在籍・月計・達成率・残り必要数・月次サマリー |
| 上司報告 | 日報・週報・月報・緊急報告のルールと、貼って使える定型文 | — |
| 判断基準 | 迷ったとき。しきい値に触れたら自分で決めずに上げる | — |

- **黄色と青字のセルが記入欄**。白地の数式セルは触らなくてよい。
- チェック欄は `✓`（実施）と `ー`（実施せず）の2つだけ。**空欄は未記入扱い**で実施率の分母に入らないので、月の途中でも率が正しく出ます。
- 実施率が **90%を下回ると赤**。週次のふり返りは赤い行だけ見ればよい。
- KPI記録の在籍会員数は「月初の在籍 ＋ 入会の累計 − 退会の累計」で自動計算します。**月初の在籍数（B7）を必ず入れてください**。
- 月次サマリー（純増・退会率・体験→入会率・会員単価・会員1人あたりセッション数）が、そのまま月報に書き写せます。

## ② 会員手続き書類（6シート）

| シート | 内容 |
|---|---|
| ①入会同意書 | 会員情報・緊急連絡先・健康状態の申告（10項目）・コースと料金・同意事項11項目・写真掲載の可否（任意）・署名・親権者署名・店舗記入欄 |
| ②休会届 | 休会期間・理由・休会費と締切の確認・署名・店舗処理チェック |
| ③退会届 | 退会希望日・理由（12項目）・貸与物返却と精算の確認・署名・引き止めの打ち手記録 |
| ④受付台帳 | 受付日・種別・締切内か・署名確認・決済変更・処理状況（未処理は赤）。種別ごとの件数を自動集計 |
| ⑤手続きルール | 入会・休会・再開・退会・プラン変更それぞれの締切と社内フロー、書類の保管ルール |
| ⑥法務チェック | **配布前に確認すること**（下記） |

> ### ⚠ 配布する前に必ず
> - `◯` と `（要確認）` の箇所（締切日・金額・キャンセル規定・支払日）を**店舗の規定で埋める**。空欄のまま配布しない。
> - 契約期間が2ヶ月を超え、支払総額が5万円を超える場合、**特定商取引法の「特定継続的役務提供」**に当たります。契約書面の交付・クーリング・オフ（8日間）・中途解約時の精算ルールの明示が必要です。金額の記載は契約書面と一致させてください。
> - 同意書の【安全】条項は「**当ジムの責めに帰すべき事由による場合を除き**」に限定してあります。「一切責任を負わない」に書き換えると消費者契約法で無効になりえます。**この表現は変えないでください**（テストでも検知します）。
> - 健康情報は**要配慮個人情報**です。施錠保管と閲覧者の限定を行ってください。
> - 最終文面は**弁護士等の専門家の確認**を受けてから運用してください。この書式はひな形です。

## ③ シフト表（4シート）

| シート | 内容 |
|---|---|
| シフト表 | スタッフ×日付に記号（A早番／B中番／C遅番／D短時間／研／休／有）を入れる。右に出勤日数・労働時間・人件費の目安 |
| シフト記号 | 記号の開始・終了・休憩・**実働時間**。ここを直すと労働時間の計算も変わる |
| 希望シフト | スタッフに配って ○×△ を提出してもらう。日ごとの「出勤できる人数」が出る |
| 集計・労務チェック | スタッフ×週の労働時間（**40時間超は赤**）、人件費合計と人件費率、労務の注意チェック |

自動で赤くなるところ（ここだけ見れば穴が分かります）：

- **過不足** … その日の出勤人数が必要人数を下回る
- **開店／閉店** … 開店をカバーする記号（A・研）や閉店をカバーする記号（C・D）が誰も入っていない日は `×`
- **週の労働時間** … 40時間を超えた週
- **人件費率** … 目安（既定30%）を超えたとき

> 労働時間・休憩・休日の扱いは就業規則と雇用契約が優先です。この表は目安なので、
> 36協定・割増賃金・未成年の深夜勤務などは社労士に確認してください。

## 運用の回し方

| いつ | やること |
|---|---|
| 毎月1日 | `npm run store:all`（または Actions）で当月分を作り直して配布 |
| 毎日 閉店後 | KPI記録を入力 → 日次チェックに ✓ → 日報を送信（閉店後30分以内） |
| 毎週月曜 | 週次チェックの数値ふり返り → 週報（12時まで） |
| 毎週水曜 | 翌週シフトの確定・予約枠の公開 |
| 毎週金曜 | 休会・退会の申請処理（締切前の取りまとめ）・設備点検 |
| 前月25日 | 翌月シフトの確定（希望提出は前月◯日まで・要確認） |
| 翌月3日 | 月報（数字＋原因＋打ち手3つ） |
| 翌月5日 | 習得状況の更新と、このセットの見直し（月次チェックの最後の項目） |

記入済みのExcelは**月ごとに別ファイルで残す**（例：`シフト表_梅田店_2026-10.xlsx`）。
翌月分は生成し直したまっさらな方を使ってください。
