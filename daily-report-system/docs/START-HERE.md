# 👉 まずはここから（ど素人向け・これだけ読めばOK）

パソコンが得意でなくても大丈夫です。**やることは3つだけ**です。

---

## 用意するもの（3つ）

| # | もの | どこで手に入るか | 所要 |
|---|------|------------------|------|
| 1 | KintoneのログインIDとパスワード | いつも使っているもの | 0分 |
| 2 | Claudeの「APIキー」 | https://console.anthropic.com → API Keys → Create Key | 5分 |
| 3 | LINEの「アクセストークン」 | https://developers.line.biz （`docs/line-setup.md` に手順あり） | 15分 |

> **2と3は後回しでOK**です。1（Kintone）だけあれば、まず動き始められます。

---

## やること①：設定する

黒い画面（ターミナル）を開いて、次を1行ずつ入力します。

```bash
cd daily-report-system
npm run setup
```

あとは**画面の質問に答えるだけ**です。

- 分からない質問は、そのまま **Enterキー** を押せば飛ばせます（後から設定できます）
- 入力した値は、その場で「本当に繋がるか」自動で確認してくれます
- 間違えても、もう一度 `npm run setup` をやり直せばOKです

このとき、システムが自動でやってくれること：

- ✅ あなたのKintoneから「日報アプリ」を探し出す
- ✅ 足りない項目（報告日・緊急度・提出状況など）を自動で追加する
  - **今あるデータや項目には一切触りません。安全です。**
- ✅ 「AI経営日報」アプリを新しく作る

その通りにして、もう一度 `npm run doctor` を実行してください。

## やること③：実際に動かしてみる

```bash
npm run pipeline
```

これで「日報を集める → AIが分析する → Kintoneに保存する → LINEに送る」が全部動きます。

**最初は「テストモード」なので、LINEには実際には送信されません。**
画面に「こういう内容が送られます」というプレビューが出るだけなので、安心して試せます。

内容を見て納得できたら、本番に切り替えます：

1. `daily-report-system/.env` というファイルを開く
2. 一番下の `APP_ENV=test` を `APP_ENV=production` に書き換える
3. 保存して、もう一度 `npm run pipeline`

→ これで実際にLINEへ届きます。

## 毎日自動で動かすには

ここまでできたら、あとは「毎日決まった時間に自動実行」の設定です。
2つやり方があります。

- **かんたん**：パソコン／サーバーの定時実行（cron）に `npm run pipeline` を登録
- **本格的**：n8n というツールに、用意済みの設定ファイルを読み込ませる
  → `n8n/workflow-1-daily-report.json` を読み込むだけ。手順は `docs/setup-guide.md`

**どちらでも同じことができます。** まずは手動で `npm run pipeline` を何日か試して、
内容に満足してから自動化するのがおすすめです。

## よくある質問

**Q. 間違えてデータを消してしまわない？**
A. 大丈夫です。このシステムは日報を**読むだけ**で、書き換えたり消したりしません。
　 項目の追加も「足りないものを足す」だけで、今あるものには触れません。

**Q. スタッフの入力の仕方は変わる？**
A. 基本は変わりません。今の日報の書き方をそのまま続けてもらってOKです。
　 ただし「提出したら『提出状況』を提出済みにする」だけ、お願いしてください。
　 （これが無いと、書きかけの日報まで集計してしまうためです）

**Q. お金はかかる？**
A. Claudeの利用料（1日1回の分析なら月数百円程度）と、LINEの送信通数によります。
　 Kintoneとn8nは今お使いのプラン次第です。

**Q. 途中でやめたくなったら？**
A. `.env` の `APP_ENV=test` に戻せば、LINEへの送信は止まります。
　 追加した項目が不要なら、Kintoneの設定画面から削除できます。
