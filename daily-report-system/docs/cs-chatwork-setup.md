# Chatwork「CSレビューコピペ」グループの設定

レビュー返信の下書きが届く専用グループの設定手順です。
**経営向けの通知と混ざらないように、部屋を分けています。**

> ✅ **設定済み**：グループ「CSレビューコピペ［自動連携］」を作成し、
> `.env` の `CHATWORK_CS_ROOM_ID` に設定済みです。
> 以降、レビュー返信の下書きは**このグループにだけ**届きます。
> （以下は、部屋を作り直すときの手順です）

---

## 1. グループを作る

1. Chatwork左上の **「＋」→「グループチャットを新規作成」**
2. グループ名: **`CSレビューコピペ［自動連携］`**
3. メンバー: CS担当・アルバイト・確認役の社員
4. 作成

## 2. ルームIDを調べる

作ったグループを開き、ブラウザのURLを見ます。

```
https://www.chatwork.com/#!rid123456789
                              ↑ この数字がルームID
```

スマホアプリの場合は、PCブラウザで開いて確認してください。

## 3. `.env` に1行足す

```
CHATWORK_CS_ROOM_ID=（調べた数字）
```

これを入れると、レビュー返信の下書きは**このグループにだけ**届きます。
入れない場合は、いつもの通知先に届きます。

---

## 届く形

```
📝 楽天レビュー返信（2026/7/30分・全8件）

🟢 そのまま貼れる: 6件
🔴 社員の確認が必要: 2件

【作業手順】
1. RMS →「レビュー・注文サポート」→「レビューチェックツール」を開く
2. 下の順番どおりに、対象のレビューを探す
3. 🟢 は下書きをそのままコピーして貼り、投稿する
4. 🔴 は投稿せず、このグループで社員に声をかける
5. 投稿できたら、このメッセージに 👍 を付ける

※ 迷ったら投稿しないでください。あとで直すより聞くほうが早いです。

━━━━━━━━━━━━━━━━━━
【1/8】 ★5　2026/07/29　ポンコナンさん
🟢 そのままコピーして貼ってください

▼ お客様のレビュー
お手紙がついていたり、カードホルダーが綺麗な封筒に入っていたり。梱包も綺麗。

▼ 返信の下書き（ここから ↓↓↓ ）
- - - - - - - - - -
弊社楽天ショップをご利用いただき誠にありがとうございます。
（略）
- - - - - - - - - -
（ここまで ↑↑↑ をコピー）
```

---

## アルバイトに伝えること（これだけ）

1. **🟢 は、区切り線の間をコピーして貼るだけ**
2. **🔴 は絶対に貼らない。** グループで社員に聞く
3. **迷ったら投稿しない**

判断が要るのは 🔴 だけです。それ以外は作業として完結します。

---

## 毎日決まった時刻に届くようにする

まずは手動で数日試してください。

```bash
npm run replies -- --dry-run   # 画面で確認だけ
npm run replies                # 実際に送る
```

文面が実務に耐えると確認できたら、n8n に登録して自動化します。
**いきなり自動化しないでください。** 最初の数日は必ず人が目を通してください。

---

## 運用の目安

| | |
|---|---|
| 実行する時刻 | 朝10時ごろ（前日分がまとまる） |
| 1回の件数 | 10件まで（`--limit` で変更可） |
| 費用 | 1件1円未満。1日10件でも月100円ほど |

---

## なぜ専用グループに分けるのか

いまの通知（日報・売上・経営ブリーフィング）は**社長が読むもの**です。
レビュー返信は**手を動かす作業指示**です。

同じ部屋に混ぜると、

- アルバイトが経営数字を見てしまう
- 作業指示が経営の通知に埋もれる

の2つが起きます。**分けるのが正解です。**
