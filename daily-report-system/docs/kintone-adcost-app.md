# Kintone「広告費」アプリ 設計書

媒体ごとの ROAS を出すためのアプリです。
**合算では「どの媒体を止めるべきか」が分かりません。**

---

## 作り方

```bash
npm run create-business-apps -- adcost
```

中身だけ確認したい場合は `-- --dry-run`。

---

## 項目

| 項目名 | 種類 | 必須 | 備考 |
|---|---|---|---|
| 日付 | 日付 | ○ | |
| 媒体 | ドロップダウン | ○ | Meta広告 / RPP(楽天) / Amazon広告 / Google広告 / その他 |
| キャンペーン/種別 | 文字列(1行) | | 媒体内の内訳（スポンサープロダクト等） |
| 広告費 | 数値 | ○ | 単位「円」 |
| 表示回数 | 数値 | | |
| クリック数 | 数値 | | |
| 注文数 | 数値 | | |
| 広告経由売上 | 数値 | | 単位「円」 |
| ROAS | 計算 | | `IF(cost > 0, conversion_value / cost, 0)` |
| クリック単価 | 計算 | | `IF(clicks > 0, cost / clicks, 0)` |
| 注文獲得単価 | 計算 | | `IF(conversions > 0, cost / conversions, 0)` |
| 備考 | 文字列(複数行) | | |
| 重複防止キー | 文字列(1行) | | **「値の重複を禁止する」にチェック** |

---

## 計算式に `IF` を入れている理由

広告を止めた日は広告費が 0 になります。
`conversion_value / cost` だけだと **0で割ることになりエラー表示**になります。

`IF(cost > 0, ...)` を挟むことで、広告を止めた日も表がきれいなままです。

---

## データの取り方

| 媒体 | 取得方法 | 自動化 |
|---|---|---|
| Meta広告 | 広告マネージャ → レポート → エクスポート | ◯ Marketing API で自動化しやすい |
| RPP(楽天) | RMS → 広告 → RPP → 実績ダウンロード | △ APIが無いためCSV運用 |
| Amazon広告 | 広告コンソール → レポート | ◯ Advertising API あり（要申請） |
| Google広告 | 管理画面 → レポート | ◯ Google Ads API あり |

**まずは全部CSVで始めてください。** 4媒体の数字が1画面に揃うだけで、
「どこにお金を入れすぎているか」はすぐ見えます。

---

## 注意：売上との突き合わせはKintoneでやらない

このアプリには**広告側の実績だけ**を入れます。
「広告費 ÷ 全体売上」のような全社の計算式は入れません。

理由は、ROASの定義（広告経由売上で見るか、全体売上で見るか）を
後から変えたくなったとき、**アプリに埋め込んだ式は直すのが大変**だからです。

全体の ROAS はダッシュボード側で計算します。定義の変更は1行で済みます。
