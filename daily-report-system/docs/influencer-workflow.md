# インフルエンサー案件 進行フロー（標準）

SNS・PR担当（西岡）のインフルエンサー案件を、**誰が担当しても同じ順番で進む**ように
標準化したものです。文面のひな形は [`../prompts/influencer/`](../prompts/influencer/) にあります。

---

## 1. 進行フロー（8ステップ）

```
① 案件確定
      ↓
② 発送先・サイズ等 確認
      ↓
③ 発送予定＋初稿提出目安 確認   ← ★今回の追加。必ず通す
      ↓
④ 商品発送
      ↓
⑤ 発送完了連絡＋制作指示
      ↓
⑥ 初稿提出
      ↓
⑦ 確認・修正
      ↓
⑧ 投稿日確定
```

### ③を必ず通す理由

これまでは初稿の提出目安を**事前に確認している場合・していない場合**が混在していました。
案件確定後に必ず確認する運用へ統一することで、

- こちらで大まかなスケジュールを先に把握できる
- その後の確認・修正・投稿日調整まで見通しを持って進められる
- 都度こちらから進捗確認する工数が減る

という状態を作ります。③で聞いた目安は、⑤の制作指示文の冒頭に**そのまま書き戻します**
（「先日ご共有いただいた○月○日頃のご提出予定で承知しております」）。

---

## 2. 各ステップでやること

| # | ステップ | こちらの作業 | 確認・記録すること |
|---|---|---|---|
| ① | 案件確定 | 条件（報酬・投稿本数・媒体）の合意 | 案件種別／対象商品／報酬・条件 |
| ② | 発送先・サイズ等 確認 | 発送先住所・氏名・電話、紹介サイズを確認 | 紹介サイズ（S / M / L） |
| ③ | 発送予定＋初稿提出目安 確認 | 発送予定日を伝え、**初稿の提出目安を必ず質問** | 初稿提出目安（日付 or 「商品到着後○日程度」） |
| ④ | 商品発送 | 発送手配 | 発送日 |
| ⑤ | 発送完了連絡＋制作指示 | 制作指示文を送付（ひな形から作成） | 使用した制作指示パターン |
| ⑥ | 初稿提出 | 目安日を過ぎたらこちらから確認 | 初稿受領日 |
| ⑦ | 確認・修正 | 動画／キャプション／ストーリーの内容確認・修正依頼 | 修正回数・内容 |
| ⑧ | 投稿日確定 | 投稿日を決定。ストーリー③の指定期間もここで相談 | 投稿確定日／ストーリー3回の実施状況 |

---

## 3. 制作指示文のひな形

⑤で送る制作指示文は、インフルエンサー様のタイプで3種類を使い分けます。

| # | パターン | 想定するインフルエンサー | ファイル |
|---|---|---|---|
| ① | 顔ファン・ファッション系 | 世界観・ライフスタイルを見られている方 | [`多機能PC-01-顔ファン・ファッション系.md`](../prompts/influencer/多機能PC-01-顔ファン・ファッション系.md) |
| ② | バズ・CV型 | 機能性・テンポで数字を取る方 | [`多機能PC-02-バズCV型.md`](../prompts/influencer/多機能PC-02-バズCV型.md) |
| ③ | フィード投稿 | 動画ではなくフィード投稿の方 | [`多機能PC-03-フィード投稿.md`](../prompts/influencer/多機能PC-03-フィード投稿.md) |

③の質問文（初稿提出目安の確認）のたたき台は
[`共通-03-発送予定＋初稿提出目安の確認.md`](../prompts/influencer/共通-03-発送予定＋初稿提出目安の確認.md) にあります。

**送る前に必ず差し替える箇所**は各ファイルの「社内メモ」に書いてあります（要約）。

- `○○様` … インフルエンサー名
- `○月○日頃` … ③で確認した初稿提出目安
- サイズ … 紹介するサイズ（S / M / L）に差し替え
- `（投稿URL）` `（URL）` … 参考投稿・商品リンク・専用クーポンリンク
- ②のみ：投稿の「例）」部分をジャンル・視聴者層に合わせて変更

## 5. kintone「案件依頼」アプリとの対応

進行状況は kintone の **案件依頼（インフルエンサー・PR管理）アプリ**（app=36）で管理します。

| フロー | ステータス |
|---|---|
| ① 案件確定前 | 依頼前 → 依頼中（返事待ち） → 承諾 |
| ② 発送先・サイズ等 確認 | 発送先・サイズ確認中 |
| ③ 発送予定＋初稿提出目安 確認 | 初稿提出目安 確認中 |
| ④ 商品発送 | 商品発送済 |
| ⑤⑥ 制作指示〜初稿提出 | 初稿待ち |
| ⑦ 確認・修正 | 初稿確認・修正中 |
| ⑧ 投稿日確定 | 投稿日調整中 → 投稿待ち → 投稿済 → 完了 |

対応する項目：

| 項目 | 使いどころ |
|---|---|
| 紹介サイズ | ②で確認したサイズ |
| 初稿提出目安 / 初稿提出目安メモ | ③で確認した内容（日付が未定なら「商品到着後○日程度」をメモへ） |
| 発送日 | ④ |
| 制作指示パターン | ⑤で送ったひな形（①②③） |
| 初稿受領日 | ⑥ |
| 投稿確定日 | ⑧ |
| ストーリー投稿 | 3回（①商品リンク／②クーポン／③指定期間中）の実施チェック |

一覧ビュー **「⏳ 初稿待ち」** は、初稿提出目安の早い順に並びます。
目安を過ぎているものはここで一目で分かるので、③で目安を必ず埋めておくことが前提です。

### 既存アプリへの反映

上記の項目・ステータスを既存アプリ（app=36）へ追加するには：

```bash
cd daily-report-system
npm run kintone:anken-flow
```

GitHub Actions の **「案件依頼アプリ 進行フロー更新（手動）」** からも実行できます。
**既存のステータス選択肢・レコードは消さず、追加だけ**行います。
