# Kintone 設定書 ①：スタッフ日報アプリ

スタッフが毎日入力する日報アプリの設計書です。
`node kintone/createApps.js staff` で自動作成できますが、手動で作る場合はこの表のとおりに設定してください。

- **アプリ名**：`スタッフ日報`
- **1レコード**：スタッフ1名の1日分
- **フィールドコード**：`lib/normalize.js` と一致必須（変更する場合は両方直す）

---

> - システムは「**提出状況 = 提出済み**」のレコードだけを集計します（下書きは無視）。
> - 「**緊急度 = 緊急**」のレコードがあると、Claude が全体評価を 🔴 にします。
> - フィールドコードは半角英数字。日本語コードは使わないでください。

## APIトークンの発行（重要）

1. アプリを開く → 右上の歯車（設定）→ **APIトークン**
2. 「生成する」→ 権限は **レコード閲覧** のみチェック（最小権限）
3. トークン文字列をコピー → `.env` の `KINTONE_API_TOKEN_DAILY_REPORT` に設定
4. **設定を「アプリを更新」で反映**（これを忘れるとトークンが有効化されません）

> 緊急通知(ワークフロー②)で「通知済み更新」を使う場合は、閲覧に加えて **レコード編集** 権限も付けてください。

---

## Webhook（緊急即時通知を使う場合・任意）

1. アプリ設定 → **Webhook** → 追加
2. 通知先URL：`N8N_WEBHOOK_URL`（ワークフロー②の Webhook URL）
3. 対象イベント：レコードの追加・編集
4. 送信時に共有シークレットを付けたい場合は、kintone Webhook では任意ヘッダを付けられないため、
   代わりに **プロセス管理 + Webhook中継** か、n8n 側でボディ内の固定トークンを検証する構成にします
   （詳細は `docs/error-handling.md` の「Webhook保護」を参照）。
