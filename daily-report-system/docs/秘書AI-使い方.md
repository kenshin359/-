# AI秘書（1日タスク最適化）の使い方

パソコンが得意でなくても大丈夫です。**やることは朝1回、夜1回だけ**です。

---

## 使い方は2通りあります

### ① Claude に貼るだけ（いちばんラク）

Claude に **「秘書」** と送り、続けて今日のタスクを箇条書きで貼ります。

```
秘書
・楽天のLP改修
・新商品リサーチ
・画像作成依頼
・13:00-14:00 EC部署MTG
・メール返信
```

Claude がこのツールを実行して、そのまま結果を返します。

### ② 自分のパソコンで動かす

```bash
cd daily-report-system
npm run secretary          # タスクを貼り付けて、最後に Ctrl+D
```

ファイルにまとめてある場合：

```bash
npm run secretary -- --file=today.txt
```

---

## 書き方（ふつうの箇条書きでOK）

そのまま書いて大丈夫です。足すと精度が上がる目印は次のとおり（**全部省略できます**）。

| 書き方 | 意味 | 例 |
|---|---|---|
| `90分` `1.5時間` | かかる時間 | `・LP改修 90分` |
| `13:00-14:00` | 時間が決まっている予定 | `・13:00-14:00 部署MTG` |
| `@佐藤` | 依頼する相手が決まっている | `・画像作成依頼 @佐藤` |
| `!` `!!` `!!!` | 緊急（多いほど緊急） | `・通関の連絡 !!` |
| `〆9/10` `締切:今日` | 締切 | `・ビザ申請 〆9/10` |
| `#THINK` | 分類を手で指定 | `・在庫の件 #THINK` |

見出し行（`━━━`, `## 午前`, `やること:`）は自動で無視します。

---

## 夜（30秒）

終わった仕事を記録します。これをやるほど、翌朝の精度が上がります。

```bash
npm run secretary -- done "LP改修" --minutes=110    # 終わった（実際は110分かかった）
npm run secretary -- drop "競合分析"                 # やらないと決めた
npm run secretary -- status                          # 今日の残りを見る
```

**終わらなかった仕事は、何もしなくても翌朝のリストに自動で戻ってきます**（何日連続で持ち越しているかも表示されます）。

---

## 週に1回（1分）

```bash
npm run secretary -- review --days=30
```

- この種類の仕事は見積もりの何倍かかっているか
- 午前・午後・夕方で、どこの完了率が低いか
- 何日も後回しにしている仕事はどれか
- そろそろ人に任せた方がいい仕事はどれか

---

## 直したくなったら

コードを触る必要はありません。**JSONの数字を書き換えるだけ**です。

| 直したいこと | 開くファイル | 場所 |
|---|---|---|
| 起床・就寝、時間割の区切り | `config/secretary/profile.json` | `blocks` |
| 昼寝や休憩の長さ | 同上 | `blocks` の `nap` / `break-pm` |
| 「15時以降はTHINK禁止」の時刻 | 同上 | `rules.think_cutoff` |
| 何を重く見るか（売上か、緊急か） | 同上 | `weights` |
| 「今日絶対終わらせる」の件数 | 同上 | `rules.must_do_count` |
| 分類がズレる言葉 | `config/secretary/rules.json` | `categories.○○.keywords` |
| 誰に振るか（担当者名） | 同上 | `delegate_targets` |

`delegate_targets` は最初は「デザイン担当」「経理担当」のような役割名で入っています。
**実際のスタッフ名に書き換えると、朝一の依頼リストがそのまま指示書になります。**
