# 自動送信の設定（GitHub Actions）

決まった時刻に、こちらが何もしなくても Chatwork へ届くようにする設定です。
パソコンを開いていなくても動きます。

| 何を | いつ | どこへ |
|---|---|---|
| CSレビュー返信の下書き | **毎朝 8:00** | Chatwork CSグループ |
| 売上レポート（分析＋簡易シート） | **毎晩 19:00** | Chatwork テスト用グループ |

時刻はすべて日本時間です。

---

## なぜ GitHub Actions を使うのか

「19:00に送る」と設定ファイルに書いても、**それを読んで実行する場所**が無いと動きません。
GitHub Actions は GitHub 側の機械が決まった時刻に動かしてくれます。

- 公開リポジトリなので**利用は無料**です
- 社内のパソコンを付けっぱなしにする必要がありません
- 失敗したときはメールで通知が届きます

---

## 手順は3つだけです

### ① 鍵（Secrets）を登録する

リポジトリの画面で
**Settings → Secrets and variables → Actions → New repository secret**

下の名前で1つずつ登録します。値は普段お使いのものです。

**売上レポート（19:00）に必要**

| 名前 | 中身 |
|---|---|
| `KINTONE_BASE_URL` | Kintone のURL |
| `KINTONE_USER` | Kintone のログインID |
| `KINTONE_PASSWORD` | Kintone のパスワード |
| `KINTONE_SALES_APP_ID` | 売上・転換率報告アプリのID |
| `CHATWORK_API_TOKEN` | Chatwork のAPIトークン |
| `CHATWORK_SALES_ROOM_ID` | テスト用グループのルームID |

**CSレビュー（8:00）に必要**

| 名前 | 中身 |
|---|---|
| `CHATWORK_API_TOKEN` | 上と同じ（1回登録すれば両方で使えます） |
| `CHATWORK_CS_ROOM_ID` | CSグループのルームID |
| `RAKUTEN_SHOP_ID` | 楽天のショップID |
| `RAKUTEN_ITEM_IDS` | 商品レビューも見る場合の商品ID（任意・カンマ区切り） |
| `ANTHROPIC_API_KEY` | 返信文をお客様に合わせて書くために必要 |

> **Secrets に入れた値は、画面上でも実行ログでも見えません。**
> 登録した本人でも後から中身を見ることはできない仕組みです（入れ直しは可能）。

### ② 既定のブランチを変える

**Settings → General → Default branch** を
`claude/kintone-daily-report-system-f8migr` に変更してください。

**理由:** GitHub の定時実行は「既定のブランチ」に置かれた設定しか動かしません。
いまの既定は古いブランチのままなので、そのままでは8:00にも19:00にも動きません。

いまの既定ブランチの中身は、新しいブランチにすべて含まれています。**消えるものはありません。**

### ③ 一度だけ手で動かして確かめる

**Actions タブ** →左の一覧から動かしたいものを選ぶ→ **Run workflow**

うまくいけば Chatwork に届きます。
設定が足りない場合は「どの設定が足りないか」が画面に赤字で出ます。

---

## 二重送信を防ぐしくみ

定時実行のたびに、まっさらなサーバーが用意されます。
そのままだと「どこまで送ったか」を忘れて、**毎回おなじ内容を送り続けてしまいます。**

そこで、送信が終わったら記録ファイルだけをリポジトリに保存しています。

| ファイル | 中身 |
|---|---|
| `state/notified-sales.json` | 売上を通知した**日付だけ** |
| `state/replied-reviews.json` | 下書きを作ったレビューの**識別子だけ** |

金額・お客様の氏名・レビュー本文は入りません。

---

## 公開リポジトリでの安全対策

このリポジトリは公開設定のため、**実行ログも第三者から見えます。**

- CSレビューの処理は `--quiet` を付けて実行しています。
  レビュー本文と投稿者名を**ログに出しません**（Chatworkには通常どおり届きます）
- 鍵は Secrets に入れているため、ログには `***` としか出ません
- 売上の実データ（CSV）はリポジトリに置かない設定です（`.gitignore`）

---

## 止めたいとき

**Actions タブ** → 該当のワークフロー → 右上「…」→ **Disable workflow**

これで定時実行が止まります。再開も同じ場所からできます。

---

## うまく動かないときの見かた

**Actions タブ**を開くと、実行の履歴が一覧で出ます。
赤い×が付いているものをクリックすると、どこで止まったかが読めます。

| 表示 | 意味 | 対応 |
|---|---|---|
| `次の設定（Secrets）が足りません: …` | 鍵の登録もれ | ①をやり直す |
| `新しく通知した日はありません` | 正常（新しいデータが無かっただけ） | 対応不要 |
| `新しいレビューはありません` | 正常 | 対応不要 |
| `HTTP 401` | 鍵が違う／期限切れ | Secrets を入れ直す |
