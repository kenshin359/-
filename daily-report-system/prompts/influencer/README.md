## ⑤ 制作指示文（商品 × タイプ）

⑤で送る制作指示文は、**商品**と**インフルエンサー様のタイプ**の掛け合わせで選びます。

| 商品＼タイプ | ①顔ファン・ファッション系 | ②バズ・CV型 | ③フィード投稿 |
|---|---|---|---|
| 多機能PC | [開く](./多機能PC-01-顔ファン・ファッション系.md) | [開く](./多機能PC-02-バズCV型.md) | [開く](./多機能PC-03-フィード投稿.md) |
| 多機能アルミ | [開く](./多機能アルミ-01-顔ファン・ファッション系.md) | [開く](./多機能アルミ-02-バズCV型.md) | [開く](./多機能アルミ-03-フィード投稿.md) |
| クラシックアルミ | [開く](./クラシックアルミ-01-顔ファン・ファッション系.md) | [開く](./クラシックアルミ-02-バズCV型.md) | [開く](./クラシックアルミ-03-フィード投稿.md) |

- ①顔ファン・ファッション系 … 世界観・ライフスタイルを見られている方
- ②バズ・CV型 … 機能性・テンポで数字を取る方
- ③フィード投稿 … 動画ではなくフィード投稿（静止画）の方

## 送る前のチェック（共通）

- [ ] `○○様` … インフルエンサー名に差し替えた
- [ ] `○月○日頃` … ③で確認した初稿提出目安に差し替えた
- [ ] サイズ … 紹介サイズ（S / M / L）に差し替えた
- [ ] `（投稿URL）` … 参考投稿のURLを入れた
- [ ] `（URL）` … 商品リンク／専用楽天クーポンリンクを入れた
- [ ] ②のみ：投稿の「例）」をジャンル・視聴者層に合わせて変更した
- [ ] クラシックアルミ③のみ：フィード画像の見せ方を投稿の世界観に合わせた
- [ ] 商品ごとの必須訴求・ハッシュタグが合っている（下表）
- [ ] 「社内メモ✍️」より下は**送らない**（社内向け）

## 商品ごとの違い（間違えやすい箇所）

| | 多機能PC | 多機能アルミ | クラシックアルミ |
|---|---|---|---|
| 必須訴求 | 永久保証 | アルミの高級感・重厚感／永久保証 | アルミの上質な質感・高級感／カスタムデザイン／永久保証 |
| 必須ハッシュタグ | `#リベティ` `#スーツケース` `#PR` | `#リベティ` `#アルミスーツケース` `#PR` | `#リベティ` `#アルミスーツケース` `#PR` |
| 主な機能 | 静音キャスター／USB・Type-C充電ポート／ドリンクホルダー／スマホスタンド | 同左 | ロック付きサスペンションキャスター／アルミフレーム／TSAロック／15段階キャリーバー／スマホスタンド |
| フロントオープン・キャスターロック | ○ | ○ | 記載なし |
| カラー・カスタム案内 | なし | なし | あり（本体：シルバー／ブラック、カスタム：ブラック／オレンジ／グリーン） |
| 「文言はそのまま使わなくてよい」注記 | なし | あり | あり |

## 表記の固定ルール

- 永久保証は**必須**訴求。ただし必ず注記を添える
  （「※永久保証には適用条件・対象外事項があります。詳細は公式販売ページをご確認ください。」）
- ストーリーは合計3回（①商品リンク／②専用クーポン／③指定期間中）
- 投稿前に動画（フィード画像）・キャプション・ストーリーの内容共有をお願いする
