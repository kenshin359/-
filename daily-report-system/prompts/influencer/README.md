## 送る前のチェック（共通）

- [ ] `○○様` … インフルエンサー名に差し替えた
- [ ] `○月○日頃` … ③で確認した初稿提出目安に差し替えた
- [ ] サイズ … 紹介サイズ（S / M / L）に差し替えた
- [ ] `（投稿URL）` … 参考投稿のURLを入れた
- [ ] `（URL）` … 商品リンク／専用楽天クーポンリンクを入れた
- [ ] ②のみ：投稿の「例）」をジャンル・視聴者層に合わせて変更した
- [ ] 「社内メモ✍️」より下は**送らない**（社内向け）

## サイズ表（多機能PC）

| サイズ | 宿泊目安 | 容量 |
|---|---|---|
| S（機内持ち込み対応サイズ※） | 2〜4泊 | 40L |
| M | 3〜7泊 | 65L |
| L | 7〜10泊 | 84L |

※機内持ち込み条件は航空会社・路線により異なります。

## 表記の固定ルール

- 永久保証は**必須**訴求。ただし必ず注記を添える
  （「※永久保証には適用条件・対象外事項があります。詳細は公式販売ページをご確認ください。」）
- 必須ハッシュタグ … `#リベティ` `#スーツケース` `#PR`
- ストーリーは合計3回（①商品リンク／②専用クーポン／③指定期間中）
- 投稿前に動画・キャプション・ストーリーの内容共有をお願いする
