以下は本日提出された全スタッフの日報データです。
これを分析し、システムプロンプトで指定された JSON スキーマに従って経営日報を作成してください。

- `reports` … スタッフごとの日報（配列）
  - `body` がある場合、それは**自由記述の本文**です。項目が分かれていないため、
    本文を読んで「成果・問題・依頼・承認事項・明日の予定」などを自分で読み取ってください。
    本文に書かれていないことは推測せず "情報不足" としてください。
  - `reporter` が「（氏名不明）」の場合は、そのまま扱ってよい（誰の報告か断定しない）。
  - `team` … 所属チーム（部署の代わり。無い場合もある）
- `previousIssues` … 前日までに継続確認したい課題（あれば照合し、継続中なら problems / ai_analysis で言及）
- `report_count` … 本日の提出件数（0件なら achievements 等は "情報不足"、ai_analysis に「本日の提出はありません」と明記）

注意：
- 提出件数が少ない、または内容が空欄だらけの場合は無理に埋めず "情報不足" とする。
- 「緊急度」が「緊急」の日報が1件でもあれば urgent=true とし、conclusion.status を 🔴 にする。

出力は JSON オブジェクトのみ。
