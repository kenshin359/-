# ［セカンド］予約管理・利益配分ツール

セカンドの **予約者一覧** と **利益配分の計算** をまとめた小さなツールです。
特別なアプリのインストールは不要。ファイルを開くだけで使えます。

## 中身

| ファイル | 内容 |
|----------|------|
| [`マニュアル.md`](./マニュアル.md) | 来店挑戦者向けの攻略マニュアル（編集用）。来店〜購入の流れ、デイトジャスト41の選び方。 |
| [`マニュアル.html`](./マニュアル.html) | 1枚完結マニュアル（HTML）。画像も内包し、通信なし・オフラインで閲覧可。 |
| [`マニュアル.pdf`](./マニュアル.pdf) | **スマホ配布用のPDF版**（推奨）。LINE等でそのまま送れて、どの端末でもそのまま開けます。 |
| [`見極めチェックリスト.md`](./見極めチェックリスト.md) / [`.html`](./見極めチェックリスト.html) / [`.pdf`](./見極めチェックリスト.pdf) | 出てくる人／出てこない人の特徴。来店前のロープレ・最終チェック用。 |
| [`予約者一覧.md`](./予約者一覧.md) | 予約者の管理台帳。チーム別・状況別に整理。追加・変更はこのファイルを直接編集。 |
| [`利益配分計算.html`](./利益配分計算.html) | 利益を入力すると運営／紹介者の取り分を自動計算。スマホでも動きます。 |

## 使い方

### 利益配分の計算

1. `利益配分計算.html` をスマホ／PCのブラウザで開く（ダブルタップ／ダブルクリック）。
2. 案件の **利益（万円）** を入力。
3. モデルのプリセット（サブマリーナ・デイトジャスト人気／不人気・カスタム）を選ぶと
   金額と配分比率が自動でセットされます。
4. 運営と紹介者の取り分が下に表示されます。円単位でも確認できます。

> オフラインで動作します（通信・ログイン不要）。入力値はどこにも送信されません。

## 配分ルール

**基本比率**

- 運営：**60％**
- 紹介者：**40％**

紹介者側にマージンを渡し、あとは向こうで好きなように調整してもらう想定です。

**モデル別の目安**

| モデル | 利益 | 運営 | 紹介者 | 比率 |
|--------|-----:|-----:|-------:|------|
| サブマリーナ | 50万 | 30万 | 20万 | 60 / 40 |
| デイトジャスト（人気） | 70万 | 42万 | 28万 | 60 / 40 |
| デイトジャスト（不人気） | 30万 | 15万 | 15万 | **50 / 50** |

> 不人気モデルは出にくいため、紹介者の取り分を厚くして 50/50 にすることがあります。
> ツールの「デイトジャスト（不人気）」プリセットで自動的に 50/50 になります。
> カスタムで比率を自由に変えることもできます。
