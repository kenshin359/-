# スーツケース比較ブログ（コンバージョン設計版）

**ターゲット：** 初めてスーツケースを買う20〜30代
**ゴール導線：** ブログ記事 →（CTAリンクをタップ）→ 自社サイト（比較・アフィリエイト）

「読んで理解 → 自分の条件が分かる → 今すぐ比較したくなる」という心理の流れに沿って、
自然にリンクをタップさせる構成にしています。

## 収録ファイル

| ファイル | 用途 |
|---|---|
| `article.md` | CMS入稿・編集用のMarkdown原稿（frontmatter付き） |
| `index.html` | そのまま公開できるスタイル付きHTML（CTAボタン実装済み・レスポンシブ） |
| `README.md` | 本ファイル（構成解説・使い方） |

## コンバージョン導線の設計

読者が「買いたい」と温まるタイミングに合わせて、CTAを **3か所** に配置しています。

```
 [タイトル・共感リード]        ← 課題を自分ごと化させる
        ↓
 [1.サイズ] [2.素材] [3.チェック項目]  ← 選び方を理解＝自分の条件が固まる
        ↓
 ─────────── ① 中間CTA ───────────   条件が見えた直後（温まりはじめ）
        ↓
 [4.タイプ別診断] [5.比較表]         ← 「自分はこれだ」と特定＝購買意欲ピーク
        ↓
 ─────────── ② メインCTA ──────────  最も熱い位置。ここが本命
        ↓
 [FAQ] [まとめ]                      ← 不安を解消し背中を押す
        ↓
 ─────────── ③ 最終CTA ───────────   離脱直前の最後の一押し
        ↓
     自社サイト（比較・アフィリエイト）へ
```

### なぜこの位置なのか
- **① 中間CTA**：選び方を理解して「自分の条件」が見えた直後。まだ迷いはあるが、行動の芽が出る瞬間。
- **② メインCTA**：比較表で「自分はこれ」と特定できた直後＝購買意欲が最も高い。**最重要**。
- **③ 最終CTA**：まとめで安心させたあと、ページを閉じる前の最後のフック。

いずれも「売り込み」ではなく **「最新価格を"比較して確認"するだけ」** という軽いアクションにして、心理的ハードルを下げています。

## 使い方（公開前にやること）

### 1. リンク先URLを差し替える
`{{CTA_URL}}` を自社サイト（比較ページ）のURLに置換します。

```bash
# 例：macOS / Linux。YOUR_SITE_URL を実URLに変えて実行
sed -i 's#{{CTA_URL}}#https://your-site.example.com/compare#g' index.html article.md
```

各リンクには計測用の **UTMパラメータ** を付与済みです（差し替え後もそのまま活きます）。

| 位置 | utm_medium | utm_content |
|---|---|---|
| 中間CTA | cta | mid |
| 比較表の各行 | table | itemA / itemB / itemC |
| メインCTA | cta | main |
| 最終CTA | cta | bottom |

→ GA4等で **どのCTAが一番クリックされたか** が分かるので、改善に使えます。

### 2. 比較表の中身を実データにする
`商品A / 商品B / 商品C（例）` はプレースホルダーです。実際に紹介する商品名・スペック・リンク先に差し替えてください。

### 3. 設計メモ用コメントを削除（任意）
HTML/Markdown内の `<!-- ... -->` の設計メモは公開前に消してOKです（表示はされません）。

## カスタマイズのヒント（成果を伸ばす）
- **CTAの文言はABテスト推奨**：「比較して見る」vs「無料でチェック」など。
- **ファーストビューにも軽いテキストリンク**を足すと、結論だけ知りたい層を取りこぼしません。
- **記事を増やす場合**は `article.md` をテンプレとして「機内持ち込み特集」「女性向け」等に横展開すると、内部リンクで回遊→CV率が上がります。

## プレビュー
`index.html` をブラウザで開くだけで表示を確認できます（外部依存なし・1ファイル完結）。
