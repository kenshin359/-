## 2. キーワード修正｜弱い語 → 強い語（理由つき）

> PR TIMES本文の目的は**認知・指名検索・参照流入**（SEOの被リンク効果は期待しない＝監修レビュー反映）。
> キーワードは「**読者に一瞬で伝わる・後で指名検索される**」ために入れる。

| 箇所 | 弱い例（避ける） | ✅修正案（推奨） | 理由 |
|---|---|---|---|
| タイトル冒頭 | 「新商品のお知らせ」「〜を発売しました」 | 「**【スーツケース業界初(※)】**」 | ニュース性・一覧での目立ち |
| ベネフィット語 | 「便利」「快適」「新しい」 | 「**重さが測れる**」「**重量オーバーを防ぐ**」 | 具体・検索意図に一致 |
| 製品カテゴリ | 「バッグ」「旅行用品」 | 「**ジップスーツケース／キャリーケース**」 | 検索キーワードに一致 |
| 機能キーワード | （記載なし） | 「**機内持ち込み**」「**TSAロック**」「**静音キャスター**」「**キャスターロック**」 | ビッグワードを自然に内包 |
| 課題キーワード | （記載なし） | 「**超過料金**」「**重量制限**」「**手荷物 重さ**」 | 悩み検索・共感を拾う |
| 誇大表現 | 「日本一」「唯一」「最強」 | 「**業界初(※自社調べ・〇年〇月・楽天/Amazon内)**」 | 景表法（優良誤認）回避 |
| あいまい語 | 「たくさん」「かなり」 | 「**〇kgまで計測**」「**±〇kg**」 | 数字で信頼性 |

### タイトル：修正ビフォー→アフター（例）
- ❌ Before：「リベティ、新しいジップスーツケースを発売しました」
- ✅ After：「**【スーツケース業界初(※)】持ち上げれば"今の重さ"が分かる。リベティ、重量計測機能つきジップスーツケースを発売**」
  <sub>※日本国内の楽天市場・Amazon掲載商品での自社調べ（〔調査年月〕時点）</sub>

### 配信時に設定するキーワード（例・8個前後）
`スーツケース` / `ジップスーツケース` / `機内持ち込み` / `重量計` / `重さが測れる` / `超過料金` / `キャリーケース` / `リベティ`
