# LINE公式アカウント AI自動応答（AI公式ライン）設定手順

最終更新: 2026-09-19

> 対象は **お客様向けの公式アカウント「リベティ公式」**（@219qlgbu）です。社内グループ用の「LINE監査役ボット」（`docs/line-setup.md`・`/api/line/webhook`・`LINE_CHANNEL_*`）とは別チャネル・別URL・別環境変数なので、両方を同時に使えます。

お客様がLINE公式アカウントに送ったメッセージに、AI（Claude）が **事実カードの範囲で** 自動返信します。
返品・不良・注文の確認など人が対応すべき内容は、一次回答をしたうえでスタッフに通知し、ダッシュボードの PRO「LINE顧客対応」画面に要対応として残ります。

```
お客様 ──LINE──▶ LINE公式アカウント ──Webhook──▶ ダッシュボード(Vercel) /api/line/support/webhook
                                                     │  署名検証 → 会話ログ保存 → Claude で回答生成
                                                     ├──reply──▶ お客様へ返信
                                                     └──要対応なら「#番号」付きで──▶ スタッフのLINEグループ（公式LINEを招待したグループ）
                                                                                       │
スタッフがグループで「#番号 返信文」と送る ──Webhook──▶ ダッシュボード ──push──▶ お客様へ届く
スタッフがグループで「完了 #番号」と送る ──▶ AIの自動返信が再開
```

## 流れ（Phase 1: 承認フロー）

1. **公式LINEをスタッフのグループチャットに招待する。** それだけで、そのグループが通知先として自動登録されます（IDを調べる作業は不要）。
2. お客様のメッセージをAIが **分類（17種）・レベル（1〜3）・確信度（0〜100）** つきで理解し、回答案を作ります。お客様には受付文（「内容を確認のうえ担当よりご返信いたします」）が即時に返ります。
3. グループに `【LINE #12 回答案】承認をお願いします` と、分類・お客様のメッセージ・AIの回答案・根拠（事実カードの項目）が届きます。
4. スタッフは **`#12 送信`**（そのまま送る）か **`#12 返信文`**（書き換えて送る）を送るだけ。公式LINEからお客様に届きます。書き換えた内容はAI改善用の修正データとして残ります。
5. 対応中はAIが黙り、お客様からの続きは `#12 追加メッセージ` としてグループに転送されます。**`完了 #12`** で閉じます（48時間動きが無ければ自動）。
6. 安全・法的・強いクレーム（レベル3／有人のみのカテゴリ）は、AIは案を出さず引き継ぎ文だけ返して担当者へ。
7. `一覧` `ヘルプ` `スタッフ登録` も使えます。ダッシュボード PRO「LINE顧客対応」からも承認・書き換え・対応不要ができます。

### 運用モード（カテゴリごと・管理画面で変更）

| モード | 動き | 初期値 |
|---|---|---|
| 承認して送信（APPROVAL） | 受付文を即時返信 → 回答案をグループへ → スタッフが送信 | レベル1・2のカテゴリ（Phase 1 は全部これ） |
| 自動返信（AUTO） | レベル1・確信度がしきい値（既定85）以上・根拠ありのときだけAIが直接返信。満たさなければ承認へ | なし（Phase 2 で安全なカテゴリから切替） |
| 有人のみ（HUMAN_ONLY） | AIは案を出さない。引き継ぎ文＋案件化 | クレーム・法的問い合わせ・安全性 |

## 仕組みの要点（先に読む）

- **AIが答えるのは `dashboard/config/line-ai-knowledge.json` の事実カードだけ。** 送料・返品条件・在庫・寸法など未登録の項目（「要データ」）は答えず、「担当スタッフが確認のうえご連絡します」と案内して要対応にします。答えられる範囲を広げたいときは、このJSONに事実を追記するだけです（プログラム変更不要）。
- **要対応の二重チェック。** AIの判断とは別に、コード側でも注意語（返品・返金・不良・発煙・けが等）を機械的に見ます。どちらかが該当すればスタッフ通知。
- **AIが使えないときも止まらない。** APIキー未設定・API障害時は固定の案内文（fallback）を返して要対応にします。成功したふりはしません。
- **会話はDBに残る。** 直近24時間・10往復を文脈としてAIに渡すので、「Mサイズは？」→「機内持ち込みは？」のような続きの質問にも答えられます。同じイベントの再送は二重処理しません。
- **お客様へ送れるのは登録済みグループだけ。** 他のグループに公式LINEが入っても `#番号` コマンドは受け付けません（「スタッフ登録」で通知先を移せます）。
- **LINE公式アカウントマネージャーの「チャット」画面からも返信できます。** グループを使わない運用でも成り立ちます。

## 費用の目安

| 項目 | 目安 |
|---|---|
| LINE公式アカウント | お客様への **AI返信（reply）とグループ内の応答は無料通数に数えません**。通数を消費するのは push のみ = スタッフ通知（要対応1件・追加メッセージ1件につき1通）とスタッフからお客様への返信（1件1通）。無料プランは月200通。要対応が月100件を超えるなら有料プラン（月5,000円〜）を検討 |
| Claude API | 1問答あたり数円（事実カードはキャッシュされるため2回目以降は安くなる）。月1,000問答でも数千円程度 |
| Vercel | 既存のダッシュボードと同じプロジェクトで動くため追加費用なし（Pro の関数実行時間内） |

## 手順（所要 約30分）

### ① LINE公式アカウントを用意する

お客様向けの公式アカウントを使います（社内通知用の「Libetee 日報」とは別に作るのがおすすめ）。

1. https://manager.line.biz でアカウントを作成（すでにお客様向けアカウントがあればそれを使う）
2. 「設定」→「Messaging API」→「Messaging APIを利用する」（プロバイダーは `Libetee` でOK）

### ② 応答設定（重要）

LINE公式アカウントマネージャー →「設定」→「応答設定」:

| 項目 | 設定 | 理由 |
|---|---|---|
| チャット | **オン** | スタッフが引き継いで返信できるようにする |
| あいさつメッセージ | **オンのまま** | 既存の挨拶文をそのまま使う（AI側は挨拶を送らない。AI側の文面 `bot.greeting` を使いたい場合はLINE側をオフにし、JSONの `greeting_by_bot` を true にする） |
| 応答時間 | **オフ** | 時間外にLINE側が自動応答を出さないように（AIは24時間答える） |
| 応答方法 | **手動チャット** | 「手動チャット＋応答メッセージ」だとLINEの定型応答とAIが二重に返る |
| Webhook | **オン** | AIにメッセージを渡す。⑦で Webhook URL を入れるまでは灰色で押せない（最後のスイッチ） |

### ③ 鍵を控える（LINE Developers）

https://developers.line.biz/console/ → プロバイダー → チャネル:

| 画面 | 項目 | 環境変数 |
|---|---|---|
| チャネル基本設定 | **チャネルシークレット** | `LINE_SUPPORT_CHANNEL_SECRET` |
| Messaging API設定 | **チャネルアクセストークン（長期）**（「発行」を押す） | `LINE_SUPPORT_CHANNEL_ACCESS_TOKEN` |

> ⚠️ どちらも他人に渡さないでください。チャットにも貼らず、Vercelの画面に直接入力します。

### ④ Anthropic APIキー

https://console.anthropic.com → API Keys → Create Key → `ANTHROPIC_API_KEY`。
（未設定でも動きますが、全件が固定文の案内＋要対応になります）

### ⑤ スタッフ通知先

- **LINEグループ（推奨）**: 環境変数は不要です。⑦のあと、公式LINEをスタッフのグループに招待すれば自動登録されます。
  事前に LINE Developers →「Messaging API設定」→ **「グループトーク・複数人トークへの参加を許可する」を オン** にしておいてください。
  （通知先を固定したい場合だけ `LINE_SUPPORT_STAFF_GROUP_ID` にグループIDを設定。設定すると自動登録より優先されます）
- **Chatwork（任意・併用可）**: `CHATWORK_API_TOKEN` と `CHATWORK_CS_ROOM_ID`（CS用ルーム。無ければ `CHATWORK_ROOM_ID`）。Chatworkからはお客様へ返信できません（通知のみ）。

### ⑥ Vercel に環境変数を入れて再デプロイ

Vercel → プロジェクト → Settings → Environment Variables（Production）:

| 変数 | 値 |
|---|---|
| `LINE_SUPPORT_CHANNEL_SECRET` | ③のチャネルシークレット |
| `LINE_SUPPORT_CHANNEL_ACCESS_TOKEN` | ③のアクセストークン |
| `ANTHROPIC_API_KEY` | ④のキー |
| `CHATWORK_API_TOKEN` / `CHATWORK_CS_ROOM_ID` | ⑤（任意） |

保存後、Deployments → 最新 → **Redeploy**。ビルド時に `prisma migrate deploy` が走り、会話ログ用テーブル（`LineChatLog` / `LineCase`）が自動で作られます。

### ⑦ Webhook URL を設定して検証

1. ブラウザで `https://<ダッシュボードのドメイン>/api/line/support/webhook` を開き、`configured` がすべて `true` になっていることを確認
2. LINE Developers →「Messaging API設定」→ **Webhook URL** に同じURLを入力 →「更新」→「**検証**」で「成功」
3. 「Webhookの利用」を **オン**

### ⑧ スタッフグループに招待

1. LINEアプリでスタッフのグループを作る（既存の社内グループでも可）
2. グループのメンバー追加から、**この公式アカウント**を招待する
3. グループに「通知先として登録しました」と使い方が届けば完了（ダッシュボード PRO「LINE顧客対応」の設定状態にも「スタッフグループ ● 設定済み」と出ます）

### ⑨ テスト

1. スマホで公式アカウントを友だち追加 → 挨拶文が返る
2. 「Sサイズは機内持ち込みできますか？」→ 事実カードから回答
3. 「返品したいです」→ 一次回答＋要対応。スタッフグループに `【LINE要対応 #1】` が届き、ダッシュボードの PRO「LINE顧客対応」の進行中案件に表示される
4. グループで `#1 ご連絡ありがとうございます。担当より折り返します` と送る → お客様のLINEに届く
5. お客様側から続けて何か送る → グループに `#1 追加メッセージ` として転送される（AIは返信しない）
6. グループで `完了 #1` → 以後、そのお客様にはAIが再び自動返信する

## 日々の運用

- **答えられる範囲を広げる**: `dashboard/config/line-ai-knowledge.json` の `facts` に事実を追加（例: 各サイズの寸法・重量・容量、送料、返品条件）。追加した項目は `unknown` から削除。コミット→pushで自動反映。
- **要対応の対応**: スタッフグループで `#番号 返信文` → `完了 #番号`。ダッシュボード PRO「LINE顧客対応」の進行中案件からも「完了にする」が押せます（編集者以上）。
- **グループを変える**: 新しいグループに公式LINEを招待し、そのグループで「スタッフ登録」と送る。
- **文面の調整**: 挨拶（`bot.greeting`）・案内文（`bot.fallback` / `bot.handoff`）・文体（`style`）も同じJSON。
- **注意語の追加**: `always_human.keywords`。

## うまくいかないときは

| 症状 | 原因 | 直し方 |
|---|---|---|
| Webhook「検証」が失敗（401） | チャネルシークレットが違う | ③をやり直して `LINE_SUPPORT_CHANNEL_SECRET` を入れ直し Redeploy |
| 検証が失敗（503） | `LINE_SUPPORT_CHANNEL_SECRET` が空 | ⑥を確認 |
| 返信が来ない | 「Webhookの利用」がオフ、またはアクセストークン未設定 | ②と⑦を確認。`/api/line/support/webhook` を開いて `accessToken: true` か確認。Vercel の Logs に `[line-ai]` のエラーが無いか |
| 全部「担当スタッフが確認…」になる | `ANTHROPIC_API_KEY` 未設定か無効 | ④⑥を確認。Vercel の Logs に `[line-ai] Claude API error` が出ていないか |
| 「LINE対応」画面にDBエラー | マイグレーション未適用 | Redeploy（ビルドで `prisma migrate deploy` が走る） |
| 二重に返信される | LINE側の「応答メッセージ」がオン | ②で オフ |
| グループに招待しても何も返らない | 「グループトーク・複数人トークへの参加を許可」がオフ | LINE Developers の Messaging API設定でオンにして招待し直す |
| グループで `#1 …` と送っても「登録されていません」 | 別のグループが通知先になっている | そのグループで「スタッフ登録」と送る |
| お客様にAIが返信しなくなった | その方の案件が進行中（スタッフ対応中） | グループで「完了 #番号」か、ダッシュボードで「完了にする」 |
