# Googleスプレッドシート連携の設定（北野取締役向け・クリック手順）

ダッシュボードは次のシートを **読むだけ** で表示します（書き込みはしません）。

| 画面 | シート | 環境変数 |
|---|---|---|
| PRO → 制作依頼 | 画像作成依頼シート（LPチーム） | `SHEET_LP_REQUESTS_ID` |
| PRO → SNS投稿 | SNS投稿スケジュール（Libetee） | `SHEET_SNS_SCHEDULE_ID` |
| PRO → 社内アンケート（管理職以上） | 社内アンケート（フォーム回答） | `SHEET_SURVEY_ID` |

## いまの方式（暫定）: 「リンクを知っている全員（閲覧者）」
1. シートを開く → 右上の緑「共有」を押す
2. 「一般的なアクセス」の「制限付き」を「**リンクを知っている全員**」に変える
3. 右側の役割は「**閲覧者**」（編集者にしない）
4. 「完了」。5分以内にダッシュボードに表示されます

注意: URLを知っていれば社外の人も見られる方式です。社内アンケートなど機密度が高いシートは、下の「安全な方式」に切り替えてください。

## 安全な方式（推奨）: サービスアカウントにだけ共有する
Google Cloud に「ダッシュボード専用のロボットアカウント（サービスアカウント）」を1つ作り、そのアカウントのメールアドレスにだけシートを共有します。URLが漏れても第三者は見られません。

### 北野取締役の操作（約10分・1回だけ）
1. https://console.cloud.google.com/ を開き、Googleアカウントでログイン
2. 上部のプロジェクト選択 → 「新しいプロジェクト」→ 名前 `libetee-dashboard` → 作成
3. 左メニュー「APIとサービス」→「ライブラリ」→ `Google Drive API` を検索 → 「有効にする」
4. 左メニュー「IAMと管理」→「サービスアカウント」→「サービスアカウントを作成」→ 名前 `dashboard-reader` → 「完了」
5. 作成したアカウントの行を押す → タブ「キー」→「鍵を追加」→「新しい鍵を作成」→ JSON → 「作成」（JSONファイルがダウンロードされます）
6. そのアカウントの **メールアドレス**（`dashboard-reader@libetee-dashboard.iam.gserviceaccount.com` のような形）をコピー
7. 連携したい各シートを開く → 「共有」→ このメールアドレスを貼り付け → 役割「閲覧者」→ 送信
8. ダウンロードした JSON ファイルを山本に渡す（チャットに貼らず、Vercel の環境変数 `GOOGLE_SHEETS_SA_JSON` に入れます。山本が設定する場合は安全な受け渡し方法を相談）
9. 各シートの「一般的なアクセス」を「制限付き」に戻す

### 山本の作業
- 環境変数 `GOOGLE_SHEETS_SA_JSON`（JSONを base64 にした文字列）を Vercel に設定
- `src/lib/sheets/google-sheet.ts` はこの変数があるとサービスアカウントで Drive API からエクスポートし、無ければ従来のリンク共有方式で読む（両対応）
