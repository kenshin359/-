# Meta広告 クリエイター配信管理シート

案件依頼の運用ルールを、現場で「見て・選んで・チェックできる」形にした Excel 管理シートです。
入力ミス・言い間違い・報告漏れを防ぐことを狙いとしています。

## ファイル

| ファイル | 内容 |
|---|---|
| `Meta広告クリエイター管理.xlsx` | 配布・利用する管理シート本体（これを開いて使う） |
| `generate.py` | 上記シートを生成するスクリプト（作り直し・仕様変更用） |

## シート構成

### シート1「クリエイター配信管理」（メイン）

1行1クリエイターで管理します。列は次のとおり。**▼マークの列はドロップダウン（セレクトボックス）** で選ぶだけです。

| 列 | 入力方法 | メモ |
|---|---|---|
| No. | 自動 | 名前を入れると自動採番 |
| 名前 / アカウント名 | 手入力 | アカウント名は `@` 付き推奨 |
| タイアップ投稿 ▼ | 予定／依頼済／投稿済／見送り | 案件はタイアップ投稿を必須 |
| 事前確認 (Meta広告で配信OKか) ▼ | 未確認／確認中／OK／NG | 文言ルール（下記②）に従って確認 |
| Meta広告 利用可否 ▼ | 利用可／利用不可／確認中 | **可＝緑 / 不可＝赤 / 確認中＝黄** に色分け |
| 投稿日 | 日付入力 | 入れると報告期限が自動計算 |
| 配信可否 報告期限 (投稿+3日) | 自動 | 期限を過ぎると赤くなる |
| 配信可否 報告済 ▼ | 済／未 | |
| 配信予定日 | 日付入力 | |
| 配信済み ▼ | 済／未 | |
| 備考 | 手入力 | |

- 5行目は**見本行**（薄い青）です。使うときは上書きするか削除してください。
- ヘッダーは固定表示＆オートフィルタ付き。並べ替え・絞り込みができます。

### シート2「運用ルール・凡例」

案件依頼の運用ルール（①〜④）、色の意味、各列の入力の手引きをまとめています。

## 運用ルール（要点）

1. **タイアップ投稿を必須**とする。
2. **「二次利用」という表現は使わない。**
   「投稿いただいた動画を弊社のMeta広告で配信しても問題ないでしょうか？」と事前確認する。
   （「二次利用」だと HP や各種媒体への掲載まで含むと受け取られる恐れがあるため）
3. Meta広告で**利用可能／利用不可のクリエイターはこのシートで厳重に管理**する（トラブル防止）。
4. Meta広告で利用できる動画は、**投稿後3日以内に配信可否を報告**する。

## 作り直し方（仕様変更したいとき）

```bash
pip install openpyxl      # 未インストールの場合
python generate.py        # Meta広告クリエイター管理.xlsx を再生成
```
