# O2GYM｜成約するLP（女性専用パーソナル美容ジム）

無料体験・カウンセリング予約の**獲得最大化**を唯一の目的に設計したランディングページです。
「見た目の美しさ」より「予約が増える設計」を優先しています。

- 実装：[`index.html`](./index.html)（1ファイル完結・インラインCSS・レスポンシブ・モバイルファースト。**本番用＝【要入力】で差し替え**）
- 見本：[`demo.html`](./demo.html)（サンプルデータを流し込んだ**確認用モックアップ**。iPhoneはSafariでそのまま開けます）
  - `_artifact.html` … demo.htmlをWebページ公開（Artifact）した際の元ファイル。数字・写真・口コミはすべてダミーです。
- 外部読み込みゼロ＝表示が速い（画像は差し込み前提の軽量プレースホルダ枠）
- 開き方：`index.html` をブラウザで開くだけ（ビルド不要）

> ⚠️ 黄色ハイライトの **【要入力】** はすべて差し替え箇所です。下記「差し替えガイド」を参照。

## 3. デザイン指針

**配色（HEX）**
| 用途 | 色 |
|---|---|
| 背景（温かみのあるクリーム） | `#FBF6F2` |
| 文字（黒に近いプラム） | `#2A2530` |
| ブランド（ローズ） | `#B4577A` ／ 濃 `#7E3B57` |
| ブランド淡（背景差し色） | `#F7E7EE` |
| 権威アクセント（ゴールド） | `#C7A15B` |
| **CTA（最重要）** | グラデ `#FF7EA6 → #E23E76` |
| 成功・肯定 | `#2E9E7B` ／ LINE `#06C755` |

- **フォント**：ヒラギノ角ゴ／Noto Sans JP系の日本語ゴシック。見出し800〜900の極太で視認性最優先。
- **余白**：セクション上下 52px、角丸14〜20pxで“やわらかく高級感”。1画面1メッセージ。
- **写真方向性**：明るい・清潔・自然光。30代女性の笑顔／通う日常／許諾済BA。作り込みすぎない“リアル”。
- **モバイルファースト**：最大幅600pxの単一カラム。CTAは指で押しやすい高さ（18pxパディング）。下部追従バーで常時予約可能。
- **視線誘導**：CTAだけを最も彩度の高いピンクに（他要素は彩度を抑える）→ Zではなく縦一直線に読ませ、要所ごとにCTAへ落とす。CTAは微パルスで注意を引く（`prefers-reduced-motion`配慮）。
- **FVインパクト演出**：ゴールド調（`#EAD7A0→#C29B48`）のBAパネル＋黒の斜めタグ＋大型イタリック数字で「変化」を一目で。参考LP（他社見本）のレイアウト思想のみ採用し、数字・人物は自社実績に置換。
- **プレビュー**：`assets/preview-fv.png`（モバイルFV）・`assets/preview-full.png`（全体）で仕上がりを確認できます。

## 4. CVRを上げた根拠（なぜ成約に効くか）

1. **FVに数字＋特典＋CTA** … 3秒で「得」と「次の行動」が分かる＝直帰を防ぐ。
2. **数字4枚をヘッドライン級** … 具体数字は信頼の近道。抽象的な自慢文より効く。
3. **権威＝常駐栄養士** … 保証が無くても「続く根拠」を提示でき、不安を先回りで消す。
4. **悩み共感→仕組みへ反転** … 「自分のせいじゃない」で心理的ハードルを下げ、離脱を防ぐ。
5. **BA＋免責併記** … 変化を見せて欲求喚起しつつ、景表法・薬機法リスクを回避（信頼も上がる）。
6. **比較表で自社強調** … 「安い×多機能」を一目で。比較検討中の迷いを断つ。
7. **トレーナー顔出し** … 競合が弱い点。人が見えると安心し、予約の心理的距離が縮む。
8. **Google★の声** … 第三者評価（社会的証明）は自社コピーの何倍も効く。
9. **最安値主役＋当日特典＋残30名** … 価格の魅力＋「今動く理由」で先延ばしを封じる。
10. **FAQで不安解消** … 「勧誘・男性不可・食事」の3大不安を予約直前に処理し、最後の一押し。
11. **CTA複数＋追従バー** … 「予約したい」と思った瞬間に必ずボタンがある＝取りこぼしゼロ。

- [ ] **【要入力】数字**：平均−◯kg／◯日、累計会員◯名、達成率◯%、Google★◯・件数

- [ ] **トレーナー／管理栄養士**：氏名・資格・実績・顔写真

- [ ] **比較表**：他社名・数値の根拠と時点（景表法：客観的根拠を保持）

- [ ] **CTAリンク先**：予約フォームURL・公式LINE URL（`href="#"` を差し替え）
- [ ] **OGP画像**：SNSシェア用の画像を設定

### 法令順守メモ（景表法・薬機法）
- 「必ず痩せる」「脂肪が分解／燃焼」等の**断定・医療的表現は不使用**。
- 効果表現は「目指す」「サポート」「すっきりとした印象」等に統一済み。
- 数字・比較には**客観的根拠と時点を保持**（優良誤認・不当表示の回避）。
- BAは**許諾＋「個人差があります」併記**を全箇所に実装済み。
