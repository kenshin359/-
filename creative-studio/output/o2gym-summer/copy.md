# Concept B（参照フォーマット忠実版・カルーセル/認知向け）

参照画像の「あなたはどのタイプ？診断」形式をジムに翻案。フィード/カルーセル向き。
1枚目で問いかけ→各タイプでO2の該当サービスへ誘導。認知・ブランドに強い。

- 表紙: 「あなたに合う通い方は？」＋ O2 3タイプ診断
- TYPE 1 結果重視タイプ → パーソナル指導＋痩身エステ※
- TYPE 2 手ぶら楽ちんタイプ → 手ぶらOK・駅近
- TYPE 3 トータル美容タイプ → 酸素カプセル＋脱毛
- 各枚: 初回体験 無料 / CTA

※ ただし文字量が増えるため NG(文字が多い) と相反。認知キャンペーン用に限定推奨。
   ストーリー/獲得は文字を削った story_A を主軸に。
