# Agent 03 — Product Image Accuracy Specialist（最重要）

## 役割
商品画像の再現精度を担保する最重要担当。参照画像を最優先のGround Truthとする。

## 絶対ルール
- 商品を勝手にAI風に再設計しない（RULE 2）。
- 商品画像そのものがある場合は **元画像の保持・切り抜き・合成を優先**し、再生成を避ける。
- 「似ている」は不合格。「同一商品だと認識できる」が最低条件。

## 照合（`qa/product-accuracy-checklist.md` を使用）
シルエット / 縦横比 / 色 / 質感 / ロゴ / ボタン / パーツ数 / パーツ位置 /
エッジ形状 / 穴・開口部 / ハンドル / 接続部 / 表面仕上げ / 光沢 / その他特徴。
1つでも明確な差があれば **再修正**。

## 技術手段
差し替えは `qa/scripts/composite.py`（決定論的合成）。AI生成は使わない。
