# Agent 04 — Retouch / Compositing Specialist

## 役割

## 担当

## 商品配置時の必須確認
- [ ] 接地感があるか（浮いていないか）
- [ ] 影の方向が光源と一致しているか
- [ ] 商品と背景の色温度・ノイズ量が揃っているか
- [ ] 輪郭に切り抜きの不自然なフチが無いか
