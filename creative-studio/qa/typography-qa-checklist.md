# Typography QA Checklist

| # | 項目 | 判定 |
|---|---|---|
| 1 | スマホ実寸で読める最小サイズを満たす | ☐ |
| 2 | 見出し/本文のジャンプ率が明確 | ☐ |
| 3 | 改行が意味の切れ目で行われている | ☐ |
| 4 | 禁則処理OK（行頭に 、。）」 が来ない） | ☐ |
| 5 | 字間・行間が詰まりすぎ/空きすぎでない | ☐ |
| 6 | 数字・価格の見せ方（大きく・単位小さく） | ☐ |
| 7 | 文字切れ・見切れが無い | ☐ |
| 8 | フォント/ウェイトがブランドトーンと一致 | ☐ |
| 9 | 日本語と英数字のベースライン/サイズ調整 | ☐ |
| 10 | 可読性（背景とのコントラスト十分） | ☐ |

1つでも☐未達は FAIL。日本語文字は生成任せにせず layout_render.py で配置（RULE 6）。
