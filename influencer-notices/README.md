## 送付前に必ず埋める項目（各書面の【　】部分）

- 発信日
- 発信者（会社名・担当者名・所在地・連絡先電話/メール）
- 回答期限の具体日（推奨：本通知到達後7日〜10日以内）
- 金額欄で空欄のもの（金子真＝商品価格未記載、橋本実佳＝商品価格不明）

## 送付方法の推奨

最終告知は「相手に確実に届く」ことが重要です。可能なら複数チャネルで。

- **DM が届く相手**：Instagram DM / LINE ＋ メール
- **ブロックされている相手（金子真）**：DM は届かないため、**メール・SMS（携帯番号あり）・郵送**を優先。
- **事務所所属（吉沢朱音／株式会社Mi-So）**：本人あてに加え、**所属事務所気付**でも送付。
- 郵送する場合は、内容証明の前段階でも**特定記録郵便・レターパック等の追跡可能な方法**を推奨（送付事実を残すため）。

## 文面の考え方（法的な整理）

各インフルエンサーとの関係は、**「PR投稿の実施」を条件に商品を無償提供した業務委託（役務提供）契約**と整理できます。商品受領後に投稿義務を履行せず連絡を絶つのは**債務不履行**にあたり得ます。

そのため各書面では、相手に次のいずれかを、**期限を定めて催告**します。

1. 期限内に**約定の投稿をすべて実施**する、または
2. 実施が困難な場合は**提供済み商品の返還または相当額の支払い**（受領済みインセンティブがあればその返還を含む）

期限内に応答・履行がない場合、**弁護士による内容証明郵便・契約解除・損害賠償請求等の法的措置**に進む旨を明記しています。

## 重要な注意（免責）

- 本書面は**あくまでドラフト**です。送付前に**顧問弁護士のリーガルチェック**を受けてください。特に、請求金額の根拠、履行期限の設定、契約書面（DM・メール等の合意記録）の有無は弁護士と確認してください。
- 文面は**適法な範囲の請求・法的手続の予告**にとどめ、威迫・名誉毀損・過度な取り立てにあたる表現は避けています。送付時もこの範囲を超えないでください。
- 相手の氏名・住所・連絡先等は**個人情報**です。取り扱い・保管・共有は必要最小限にとどめてください。
- 「到着不明」の相手には、まず**受領確認と連絡**を第一に求める構成にしています（受領の立証と両立させるため）。
