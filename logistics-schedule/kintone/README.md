# キントーン連携ファイル（物流スケジュール）

| ファイル | 用途 |
|---|---|
| `物流スケジュール_import.csv` | 「物流スケジュール」アプリへの**レコード取込用CSV**（UTF-8 BOM付）。ヘッダはアプリのフィールド名に対応。Kintone > アプリ > 「ファイルから読み込む」でそのまま取込可能（コンテナ番号がキー）。 |
| `お知らせ_物流ニュース.html` | Kintoneポータル/スペースの**お知らせ（ニュース欄）貼付用HTML**。お知らせ編集のHTML表示に貼り付け。インラインスタイルで自己完結。 |

## 取込手順（CSV）
1. Kintoneで「物流スケジュール」アプリを開く（未作成なら `npm run create-app`）。
2. 右上「…」→「ファイルから読み込む」→ 本CSVを選択。
3. 文字コード UTF-8、先頭行をフィールド名として割当 → 実行。
4. 以降は同じコンテナ番号なら upsert 運用（`npm run import`）で自動集約。

## お知らせ（ニュース欄）
- ポータルの「お知らせ」編集で**HTML表示**に切替 → `お知らせ_物流ニュース.html` の中身を貼付。
- スペースのスレッドに貼る場合も同様（HTML可）。
- 内容は 2026/08/17 時点。更新は本ファイルを差し替えてください。
