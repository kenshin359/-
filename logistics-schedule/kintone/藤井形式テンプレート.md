# ［藤井形式］通関依頼テンプレート

ユーザーが「［藤井形式］」と入力したら、**書類完備で通関依頼できるコンテナ**（BL受領済み・未通関）を
BL番号ごとに以下の形式で出力する（LINEコピペ用も付ける）。

## レイアウト
```
【BL番号】
※コンテナN本   ← 同一BLに複数コンテナがある場合のみ
(サレンダー済 M/D)
▪️保税倉庫/電話:〇〇/電話番号
［リベティスタッフ必要情報］
商品名:品名＋サイズ（色・個数は不要）
コンテナ番号:XXXX
        ← 同一BLに複数ある場合は ▪️ ブロックを繰り返す
```

## ルール
- 並びはBL番号ごと。同一BL2本口は1つの【】にまとめ、▪️ブロックを2つ並べる。
- 商品名は「品名＋サイズ」のみ（色・個数は書かない）。
- 対象＝書類3点(PL/BL/AN)完備かつ未通関のコンテナ。通関完了済みは除外。
- 保税倉庫/電話が未確認のものは「要確認」と記載。
