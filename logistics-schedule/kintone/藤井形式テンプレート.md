# ［藤井形式］通関依頼テンプレート

ユーザーが「藤井形式」と入力したら、**通関依頼の対象コンテナ（未通関）**を
以下の形式で出力する（LINEコピペ用も付ける）。

## レイアウト（2026/9/6 改訂版）
```
BL番号:GZTLF2608061
保税倉庫:南港C-9 三菱倉庫
電話番号:06-6612-4861
［リベティスタッフ必要情報］
商品名:
PC多機能スーツケース M ＋ノーマルアルミ M
コンテナ番号:WHSU5516465
※9/7到着予定
```

## ルール
- 1コンテナ＝1ブロック。ブロック間は `———————————————` で区切る。
- `BL番号:` `保税倉庫:` `電話番号:` はそれぞれ独立した行（旧形式の「保税倉庫/電話」併記は廃止）。
- サレンダー日は記載しない（旧形式から削除）。
- `商品名:` はラベルのみの行にし、値は次の行に書く。
- 商品名は「品名＋サイズ」のみ（色・個数は書かない）。
- 末尾に `※M/D到着予定` を入れる。未定なら `※到着予定日 未定`。
- 未着・未確定は `未受領` / `要確認（アライバル未着）` / `未定` と明示する。
- 対象＝未通関のコンテナ。通関完了済みは除外する。
- 同一BLに複数コンテナがある場合も、コンテナごとにブロックを分けて書く。
